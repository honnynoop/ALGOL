Q1

카드 확률 문제

음의 초기하분포의 적용 예시

▶
문제: 52장의 카드에서 스페이드 4장이 있다. 비복원으로 6장을 추출할 때, 6번째 카드가 3번째 스페이드일 확률을 구하여라.

조건 분해

"6번째가 3번째 스페이드"라는 사건은 두 독립 부분으로 쪼갤 수 있습니다.

1
처음 5장의 배열 조건

처음 5장 중 정확히 스페이드 2장, 비스페이드 3장이 나와야 합니다.

경우의 수
C(4, 2) × C(48, 3)
2
6번째가 스페이드일 조건부 확률

5장이 뽑힌 후 남은 카드: 47장, 남은 스페이드: 4 − 2 = 2장

조건부 확률
2 / 47
3
전체 경우의 수

52장 중 스페이드 4장을 선택하는 방법

전체 경우
C(52, 4) = 270,725
4
확률 결합
결합 확률
P = C(4,2) × C(48,3)C(52,5) × 247
5
수치 계산

조합 값을 대입합니다: C(4,2) = 6, C(48,3) = 17,296, C(52,5) = 2,598,960

= 6 × 17,2962,598,960 × 247 = 207,552122,151,120
최종 답
92 / 54,145 ≈ 0.001699 ≈ 0.17%
✍
약분 과정: GCD(207,552, 122,151,120) = 2,256 이므로 207,552 ÷ 2,256 = 92,   122,151,120 ÷ 2,256 = 54,145
Q2

음의 초기하분포

Negative Hypergeometric Distribution

음의 초기하분포는 유한 모집단에서 비복원 추출을 할 때, r번째 성공이 몇 번째 시행에 처음 나오는가를 모델링하는 분포입니다. Q1의 카드 문제가 정확히 이 분포의 적용 사례입니다.

모수 (Parameters)

N
전체 모집단 크기
예) 카드 52장
K
성공 원소 수
예) 스페이드 4장
r
목표 성공 횟수
예) 3번째 스페이드

확률변수

정의
X = r번째 성공이 나오는 시행 번호

범위: r ≤ X ≤ N − K + r

카드 문제 예시: 3 ≤ X ≤ 52 − 4 + 3 = 51

PMF (확률질량함수)

PMF
P(X = n) = C(n−1, r−1) × C(N−n, K−r) C(N, K)
✍
직관:
• C(n−1, r−1): 앞 n−1번 중 r−1번을 성공으로 배열하는 수
• C(N−n, K−r): 남은 N−n개 중 K−r개 성공을 배열하는 수
• n번째 시행은 반드시 r번째 성공 (조합에 흡수됨)

기댓값과 분산

기댓값 E[X]
r(N+1) / (K+1)
분산 Var[X]
r(K+1−r)(N+1)(N−K) / (K+1)²(K+2)
카드 문제 E[X]
3×53 / 5 = 31.8
범위 최댓값
N − K + r

유사 분포 비교

분포 모집단 추출 방식 확률변수 관계
음의 초기하 이 단원 유한 (N) 비복원 r번째 성공까지 시행 수 —
초기하 유한 (N) 비복원 n번 추출 시 성공 수 쌍둥이 (고정값 교환)
음이항 무한 (∞) 복원 r번째 성공까지 시행 수 N → ∞ 극한
기하 (r=1) 무한 (∞) 복원 첫 성공까지 시행 수 음이항의 r=1 특수
💡
수렴 관계: N → ∞ 극한에서 음의 초기하분포는 음이항분포 NB(r, K/N)으로 수렴합니다. 모집단이 충분히 크면 복원/비복원의 차이가 사라집니다.
Q3

음이항분포

Negative Binomial Distribution — NB(r, p)

음이항분포는 매 시행이 독립이고 성공 확률 p가 일정한 베르누이 시행(복원 추출)에서, r번째 성공이 몇 번째 시행에 나오는가를 모델링합니다. 음의 초기하분포에서 모집단이 무한대가 된 버전입니다.

전제 조건 (베르누이 시행)

▶
① 매 시행은 독립    ② 성공 확률 p 고정 (매 시행 동일)    ③ 복원 추출 (무한 모집단)

모수

r
목표 성공 횟수
양의 정수, r ≥ 1
p
1회 성공 확률
0 < p < 1
q
1회 실패 확률
q = 1 − p

두 가지 정의 방식

교과서와 소프트웨어에 따라 확률변수의 정의가 다르므로 반드시 확인해야 합니다.

■ 정의 A — 한국 교과서 주류

X = 총 시행 수

r번째 성공이 나올 때까지의 총 시행 수

범위: X = r, r+1, r+2, …
■ 정의 B — scipy·위키 주류

Y = 실패 횟수

r번째 성공이 나오기 전까지의 실패 횟수

범위: Y = 0, 1, 2, …   (X = Y + r)

PMF (확률질량함수)

정의 A P(X = n)

PMF — 시행 수
P(X = n) = C(n−1, r−1) · pr · qn−r

정의 B P(Y = k)

PMF — 실패 수
P(Y = k) = C(k+r−1, k) · pr · qk
✍
PMF 직관 (정의 A):
• C(n−1, r−1): 앞 n−1번 중 r−1번 성공 배열 수
• pr: r번의 성공 확률
• qn−r: n−r번의 실패 확률
• n번째는 반드시 성공 (p는 이미 pr에 포함)

기댓값과 분산

정의 A 통계량 (X = 시행 수)
E[X] = r / p
Var[X] = rq / p²
정의 B 통계량 (Y = 실패 수)
E[Y] = rq / p
Var[Y] = rq / p² (동일)
💡
분산은 두 정의 모두 rq/p²로 동일합니다. 기댓값만 r/p (정의 A)와 rq/p (정의 B)로 다릅니다. 전환 관계: EA[X] = EB[Y] + r

특수 경우 및 관련 분포

조건 결과 분포 설명
r = 1 기하분포 Geo(p) 첫 번째 성공까지의 시행 수. 음이항분포의 특수 경우.
p → 0, r → ∞
(rp → λ 고정)		 포아송분포 Poi(λ) 성공 확률이 매우 작고 시행이 많을 때의 극한.
r = 1, p 고정 지수분포 (연속 버전) 기하분포의 연속형 대응. 무기억성 공유.
이항분포와의 관계 역관계 (Dual) 이항: n 고정 → 성공 수 관찰. 음이항: r 고정 → 시행 수 관찰.
N → ∞ 음의 초기하 음이항 NB(r, K/N) 비복원 → 복원의 극한 수렴. 모집단이 클수록 근사 정확.

p가 분포 형태에 미치는 영향

p가 클 때 (≈1)
왼쪽 편향
분산 작음
p = 0.5
대칭에 가까움
E[X] = 2r
p가 작을 때 (≈0)
오른쪽 편향
꼬리 두꺼움
최빈값 (r > 1)
floor((r−1)/p) + 1
✍
핵심 암기: 음이항분포 NB(r, p)에서 E[X] = r/p, Var[X] = rq/p² (정의 A 기준). 분산이 기댓값보다 항상 크므로 과산포(overdispersion) 모형에 자주 사용됩니다.
