             'win cash prize free offer',
             'meeting tomorrow at noon'],
})
01

단어 수 컬럼 만들기

텍스트를 공백으로 나눈 단어 개수를 counts 컬럼으로 만듭니다.

str.split().str.len()
apply의 x는 이미 문자열 하나입니다. 다시 인덱싱하거나 .str을 붙이면 안 됩니다.
✕틀린 코드 
df['counts'] = df['text'].apply(lambda x: len(x['text'].str.split()))
TypeError: string indices must be integers, not 'str'
✓고친 코드 
# ① 벡터화 (권장): 리스트로 쪼갠 뒤 길이 — NaN 안전
df['counts'] = df['text'].str.split().str.len()

# ② apply라면 x는 그냥 문자열이므로
df['counts'] = df['text'].apply(lambda x: len(x.split()))
결과 
  label                                text  counts
0   ham          lorem ipsum dolor sit amet       5
1   ham           tempor lorem ipsum dolore       4
2  spam  free money win prize click now buy       7
3  spam           win cash prize free offer       5
4   ham            meeting tomorrow at noon       4
왜? · df['text'].apply(f)에서 x는 행이 아니라 각 셀의 문자열입니다. 그래서 x.split()이 맞습니다. 글자 수(공백 포함)를 원하면 df['text'].str.len().
02

조건 필터링 — 괄호가 필수

df[(조건1) & (조건2)]
&가 ==·>보다 우선순위가 높아, 괄호가 없으면 엉뚱하게 묶여 에러납니다.
✕틀린 코드 
df[df['label']=='ham' & df['counts']>4]
TypeError: Cannot perform 'rand_' with a dtyped [int64] array ...
✓고친 코드 
# 각 조건을 괄호로 감싼다
df[(df['label']=='ham') & (df['counts']>4)]

# 또는 query (가독성 좋음, 파이썬 and/or 사용)
df.query("label=='ham' and counts>4")
규칙 · pandas 조건 결합은 &(and) · |(or) · ~(not)를 쓰고, 각 비교를 괄호로 감쌉니다. 파이썬 기본 and/or는 Series에 못 씁니다(같은 ambiguous 에러).
03

named aggregation 문법

결과 컬럼명을 직접 지정하는 집계입니다. 컬럼을 미리 선택했는지에 따라 문법이 갈립니다.

agg(이름=...) — 두 가지 형태
['counts']로 컬럼을 골랐는지가 핵심 분기입니다.
✕틀린 코드 (Series인데 튜플 사용) 
df.groupby('label')['counts'].agg(meancount=('counts','mean'))
TypeError: func is expected but received tuple in **kwargs.
✓고친 코드 
# ① 컬럼을 미리 골랐으면(SeriesGroupBy) → 이름='함수'
df.groupby('label')['counts'].agg(meancount='mean')

# ② 컬럼을 안 골랐으면(DataFrameGroupBy) → 이름=('컬럼','함수')
df.groupby('label').agg(meancount=('counts','mean'))
결과 (둘 다 동일) 
       meancount
label
ham     4.333333
spam    6.000000
튜플 함정 · ('mean')은 튜플이 아니라 그냥 문자열 'mean'입니다(1개 튜플은 ('mean',)). 그래서 agg(meancount=('mean'))은 우연히 agg(meancount='mean')과 같아 동작합니다. 여러 통계는 ②로 확장: .agg(meancount=('counts','mean'), maxc=('counts','max')).
04

agg vs mean — 무엇이 다른가

반환 타입의 차이
계산 값은 같습니다. 다른 건 DataFrame이냐 Series냐와 라벨입니다.
af = df.groupby('label')['counts'].agg(meancount='mean')   # DataFrame
bf = df.groupby('label')['counts'].mean()                  # Series
타입 비교 
af : DataFrame  | 컬럼명 = ['meancount']
bf : Series     | name   = 'counts'
값은 동일 (ham=4.333, spam=6.000)
상황추천
평균 하나만 빠르게, 바로 정렬·시각화.mean() (Series)
컬럼명을 직접 지정하고 싶을 때.agg(이름=...)
여러 통계를 한 번에.agg(평균=..., 최대=...)
이후 다른 표와 merge/join.agg(...) (DataFrame)
05

loc vs iloc — 라벨 vs 위치

groupby 결과는 인덱스가 label(ham/spam) 문자열입니다. 그래서 af.loc[0]은 실패합니다.

.loc[라벨] · .iloc[위치]
.loc은 인덱스에 실제로 있는 값, .iloc은 0부터의 정수 위치로 찾습니다.
✕틀린 코드 
af.loc[0, 'meancount']    # 인덱스가 'ham'/'spam'이라 0이 없음
KeyError: 0
✓고친 코드 
af.loc['ham', 'meancount']   # 라벨로 접근 → 4.3333
af.iloc[0, 0]                # 위치(첫 행, 첫 열)로 접근 → 4.3333
af.iloc[0]['meancount']      # 위치로 행 선택 후 컬럼

# 굳이 .loc[0]을 쓰려면 정수 인덱스로 리셋
af.reset_index().loc[0, 'meancount']
한 줄 · 인덱스가 문자열이면 .loc['ham'], "첫 번째 행"이 필요하면 .iloc[0]. 둘을 혼동해 .loc[정수]를 쓰는 게 가장 흔한 실수입니다.
06

그룹 간 차이 — ham − spam

두 그룹의 평균 단어 수 차이를 구합니다.

ham − spam 평균 차이
DataFrame이면 .loc로, Series면 키로 두 값을 빼면 됩니다.
af = df.groupby('label')['counts'].agg(meancount='mean')
bf = df.groupby('label')['counts'].mean()

# ① DataFrame: loc로 두 라벨 값을 뺀다
diff = af.loc['ham', 'meancount'] - af.loc['spam', 'meancount']

# ② Series: 키로 직접
diff = bf['ham'] - bf['spam']

# ③ diff(): 인접 행끼리의 차 (정렬 순서 주의)
af.diff()                     # spam 행에 (spam - ham)이 들어감
결과 
ham 평균 = 4.3333,  spam 평균 = 6.0000

① af.loc['ham'] - af.loc['spam'] = -1.6667
② bf['ham'] - bf['spam']          = -1.6667

③ af.diff()
       meancount
label
ham          NaN          # 첫 행은 기준 없음 → NaN
spam    1.666667          # spam - ham (= 위 결과의 부호 반대)
주의 · diff()는 "위 행과의 차"라서 인덱스 정렬 순서에 따라 부호·대상이 바뀝니다. "ham − spam"처럼 특정 두 그룹의 차를 원하면 .loc['ham'] - .loc['spam']으로 명시적으로 빼는 게 안전합니다.
