데이터 선택 & 인덱싱
loc / iloc / 불리언 인덱싱 — 핵심 차이 완전 정리
1유형2유형ADP
📌 loc vs iloc 핵심 비교
구분lociloc
기반라벨(label) 기반정수(integer) 위치 기반
행 선택df.loc[0], df.loc['A']df.iloc[0]
범위 선택끝 포함 df.loc[0:5]끝 미포함 df.iloc[0:5]
조건 사용df.loc[df['age']>30]❌ 직접 조건 불가
📌 인덱싱 방법 정리
방법문법설명
단일 컬럼df['age'] 또는 df.ageSeries 반환
복수 컬럼df[['age', 'salary']]DataFrame 반환
행 슬라이싱df[0:5]0~4번째 행
조건 필터df[df['age'] > 30]불리언 인덱싱
loc 행+열df.loc[0:5, 'age':'salary']라벨 슬라이싱
iloc 행+열df.iloc[0:5, 2:5]위치 슬라이싱
atdf.at[0, 'age']단일 값 (빠름)
iatdf.iat[0, 2]단일 값 위치 기반 (빠름)
💻 사용 예시
PYTHON
# loc — 라벨 기반
df.loc[0]                             # 0번 인덱스 행
df.loc[0:5, ['age', 'salary']]        # 0~5행, 두 컬럼 (끝 포함!)
df.loc[df['age'] > 30, 'salary']    # 조건 + 컬럼 선택

# iloc — 정수 위치 기반
df.iloc[0]                            # 0번째 행
df.iloc[0:5, 0:3]                    # 0~4행, 0~2열 (끝 미포함!)
df.iloc[-1]                           # 마지막 행
df.iloc[:, -1]                       # 마지막 열

# 복수 조건 필터링
df[(df['age'] > 30) & (df['salary'] > 5000)]
df[(df['dept'] == 'IT') | (df['dept'] == 'HR')]
df[~(df['dept'] == 'IT')]           # NOT 조건

# isin / between
df[df['dept'].isin(['IT', 'HR'])]
df[df['age'].between(30, 40)]        # 30 이상 40 이하 (양 끝 포함)

결측치 처리
isnull / fillna / dropna — 결측치 탐지와 대체
1유형 핵심3유형
📌 결측치 탐지 & 처리 함수
함수설명주요 파라미터
df.isnull()결측치 여부 (True/False)—
df.notnull()비결측치 여부—
df.isnull().sum()컬럼별 결측치 수—
df.isnull().mean()결측치 비율—
df.dropna()결측치 포함 행/열 제거axis, how, thresh, subset
df.fillna()결측치 채우기value, method, limit
df.interpolate()보간법으로 채우기method
⭐
시험 핵심: 수치형 → 평균/중앙값 대체, 범주형 → 최빈값 대체, 시계열 → ffill/bfill 대체 패턴을 암기!
💻 사용 예시
PYTHON
# 결측치 현황
df.isnull().sum()
df.isnull().sum() / len(df) * 100         # 비율 (%)

# dropna
df.dropna()                               # 하나라도 결측치 있는 행 제거
df.dropna(how='all')                     # 모든 값이 결측치인 행만 제거
df.dropna(axis=1)                        # 결측치 있는 열 제거
df.dropna(subset=['age', 'salary'])      # 특정 컬럼 기준 제거
df.dropna(thresh=5)                      # 최소 5개 비결측치 있어야 유지

# fillna — 통계값으로 채우기 (⭐ 자주 출제)
df['age'].fillna(df['age'].mean())       # 평균
df['age'].fillna(df['age'].median())     # 중앙값
df['age'].fillna(df['age'].mode()[0])   # 최빈값

# fillna — 방향 채우기
df['value'].fillna(method='ffill')       # 앞 값 (forward fill)
df['value'].fillna(method='bfill')       # 뒤 값 (backward fill)

# 컬럼별 다른 값으로 채우기
df.fillna({'age': df['age'].mean(), 'dept': 'Unknown'})

# 보간법
df['value'].interpolate(method='linear')         # 선형 보간
df['value'].interpolate(method='polynomial', order=2)

그룹화 & 집계 (groupby)
groupby / agg / transform / filter — 그룹 연산 완전 정리
1유형 핵심2유형ADP
📌 groupby 집계 함수
집계 함수설명
sum()합계
mean()평균
median()중앙값
std() / var()표준편차 / 분산
min() / max()최솟값 / 최댓값
count()비결측치 수
size()전체 행 수 (결측치 포함)
nunique()고유값 수
first() / last()첫 / 마지막 값
📌 agg / transform / apply / filter 비교
함수반환 형태용도
agg()집계된 결과 (행 수 감소)집계 통계 계산
transform()원본과 같은 크기그룹별 값을 원본 df에 붙이기
apply()자유도 높음복잡한 그룹 연산
filter()조건 충족 그룹만그룹 단위 필터링
PYTHON
# 기본 groupby
df.groupby('dept')['salary'].mean()

# 복수 컬럼 그룹
df.groupby(['dept', 'gender'])['salary'].mean()

# 여러 집계 동시에
df.groupby('dept')['salary'].agg(['mean', 'median', 'std', 'count'])

# Named aggregation ⭐ (pandas 0.25+)
df.groupby('dept').agg(
    avg_salary=('salary', 'mean'),
    max_age   =('age',    'max'),
    cnt       =('name',   'count')
)

# transform — 그룹 평균을 원본 행에 붙이기 (⭐ 자주 출제)
df['dept_avg']    = df.groupby('dept')['salary'].transform('mean')
df['salary_diff'] = df['salary'] - df.groupby('dept')['salary'].transform('mean')

# filter — 직원 수 10명 이상인 부서만
df.groupby('dept').filter(lambda x: len(x) >= 10)

# as_index=False → 결과를 일반 DataFrame으로
df.groupby('dept', as_index=False)['salary'].mean()

# reset_index
df.groupby('dept')['salary'].mean().reset_index()

병합 & 연결 (merge / concat)
merge how / concat axis — 데이터 결합 완전 정리
1유형2유형ADP
📌 merge how 파라미터
how설명SQL 동일
'inner'양쪽에 모두 있는 것만 (기본값)INNER JOIN
'left'왼쪽 기준, 오른쪽 없으면 NaNLEFT JOIN
'right'오른쪽 기준RIGHT JOIN
'outer'양쪽 모두 포함FULL OUTER JOIN
'cross'모든 조합CROSS JOIN
PYTHON
# merge 기본
pd.merge(df1, df2, on='id')
pd.merge(df1, df2, on='id', how='left')

# 컬럼명이 다를 때
pd.merge(df1, df2, left_on='emp_id', right_on='id')

# 인덱스 기준 merge
pd.merge(df1, df2, left_index=True, right_on='id')

# concat — 행 방향 (수직)
pd.concat([df1, df2], ignore_index=True)

# concat — 열 방향 (수평)
pd.concat([df1, df2], axis=1)

# concat — 공통 컬럼만 유지
pd.concat([df1, df2], join='inner', ignore_index=True)

# join (인덱스 기준 merge 단축형)
df1.join(df2, how='left', lsuffix='_left', rsuffix='_right')

피어슨 상관stats.pearsonr(x, y)상관계수 = 0
스피어만 상관stats.spearmanr(x, y)순위 상관 = 0

def remove_outliers(df, col):
    Q1, Q3 = df[col].quantile([0.25, 0.75])
    IQR    = Q3 - Q1
    return df[(df[col] >= Q1 - 1.5 * IQR) & (df[col] <= Q3 + 1.5 * IQR)]

def add_features(df):
    df['salary_rank'] = df['salary'].rank(pct=True)
    return df

result = (
    df
    .dropna(subset=['salary'])
    .pipe(remove_outliers, 'salary')
    .pipe(add_features)
    .groupby('dept')
    .agg(avg_salary=('salary', 'mean'))
    .reset_index()
    .sort_values('avg_salary', ascending=False)
)
