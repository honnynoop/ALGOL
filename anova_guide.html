00 / OVERVIEW

분산분석이란?

분산분석(ANOVA)은 세 집단 이상의 모평균이 모두 같은지를 검정하는 방법입니다. t-검정을 여러 번 반복하면 1종 오류가 누적되는데, 분산분석은 전체 분산을 "집단 간 변동"과 "집단 내 변동"으로 분해하여 한 번의 F-검정으로 비교합니다.

핵심 아이디어 — 변동의 분해 전체 변동(SST)  =  집단 간 변동(SSB)  +  집단 내 변동(SSW)

집단 간 변동(처리에 의한 차이)이 집단 내 변동(우연한 오차)보다 충분히 크면, 그 비율인 F 통계량이 커지고 "평균이 다르다"고 판단합니다.

F 통계량 F  =  집단 간 평균제곱 (MSB)집단 내 평균제곱 (MSW)  =  처리에 의한 변동우연에 의한 변동
요인의 개수 독립변수(요인)가 1개면 일원분산분석(one-way), 2개면 이원분산분석(two-way)입니다. 요인이 늘어날수록 "상호작용 효과"라는 새로운 검정 대상이 추가됩니다.
01 / ONE-WAY ANOVA

일원분산분석

하나의 요인(독립변수)이 종속변수에 영향을 주는지 검정합니다. 예: "비료 종류(A, B, C)에 따라 식물의 성장량 평균이 다른가?"

가설

  • 귀무가설 H₀ : μA = μB = μC (모든 집단의 평균이 같다)
  • 대립가설 H₁ : 적어도 한 집단의 평균은 다르다

변동의 분해와 자유도

총 표본 수를 N, 집단 수를 k라 할 때:

집단 간 (처리)SSBk − 1SSB / (k−1)MSB / MSW
집단 내 (잔차)SSWN − kSSW / (N−k)—

수치 예제 ①

세 가지 비료를 4개 화분씩 적용한 뒤 성장량(cm)을 측정했습니다. 손으로 끝까지 계산해 봅니다.

집단관측값합계평균 (x̄ᵢ)n
비료 A5, 7, 6, 8266.54
비료 B8, 9, 7, 10348.54
비료 C11, 10, 12, 94210.54
전체—1028.5 (전체평균)12
  1. 전체제곱합 SST — 모든 값에서 전체평균(8.5)을 뺀 제곱의 합
    SST = (5−8.5)² + (7−8.5)² + … + (9−8.5)² = 47
  2. 집단 간 제곱합 SSB — 각 집단평균과 전체평균의 차이
    SSB = 4·(6.5−8.5)² + 4·(8.5−8.5)² + 4·(10.5−8.5)² = 16 + 0 + 16 = 32
  3. 집단 내 제곱합 SSW — 잔차
    SSW = SST − SSB = 47 − 32 = 15
  4. 평균제곱 MS
    MSB = 32 / (3−1) = 16   |   MSW = 15 / (12−3) = 1.667
  5. F 통계량
    F = MSB / MSW = 16 / 1.667 = 9.60

집단 간32216.009.60≈ 0.006
집단 내1591.667——
전체4711———

소스 예제 ①

위 데이터를 그대로 파이썬으로 검증합니다. 간단한 검정은 scipy, ANOVA 표가 필요하면 statsmodels를 씁니다.

one_way_anova.py 
import numpy as np
import pandas as pd
from scipy import stats
import statsmodels.api as sm
from statsmodels.formula.api import ols

# --- 데이터 (주의: 변수명을 C로 쓰면 patsy의 C() 함수를 가려 오류 발생) ---
grp_A = [5, 7, 6, 8]
grp_B = [8, 9, 7, 10]
grp_C = [11, 10, 12, 9]

# --- 방법 1) scipy: F, p만 빠르게 ---
f_stat, p_value = stats.f_oneway(grp_A, grp_B, grp_C)
print(f"F = {f_stat:.4f},  p = {p_value:.4f}")
# F = 9.6000,  p = 0.0059

# --- 방법 2) statsmodels: 완전한 ANOVA 표 ---
df = pd.DataFrame({
    'growth': grp_A + grp_B + grp_C,
    'group' : ['A']*4 + ['B']*4 + ['C']*4
})
model = ols('growth ~ C(group)', data=df).fit()
print(sm.stats.anova_lm(model, typ=2))
#             sum_sq   df    F    PR(>F)
# C(group)      32.0  2.0  9.6  0.005861
# Residual      15.0  9.0  NaN       NaN
Tip 요인이 하나뿐인 일원분산분석에서는 typ=1, 2, 3 결과가 모두 동일합니다. 보정할 다른 요인이 없기 때문입니다.
02 / TWO-WAY ANOVA

이원분산분석

두 개의 요인이 동시에 종속변수에 미치는 영향을 검정합니다. 핵심은 두 요인의 주효과(main effect)뿐 아니라, 두 요인이 결합될 때 생기는 상호작용 효과(interaction)까지 본다는 점입니다.

예: 요인 A = 비료 종류(A1, A2), 요인 B = 물 주기(B1, B2) → 성장량에 대한 효과.

세 가지 가설

  • 주효과 A : 비료 종류에 따라 평균이 다른가?
  • 주효과 B : 물 주기에 따라 평균이 다른가?
  • 상호작용 A×B : "특정 비료는 특정 물 주기에서만 효과적"처럼, 한 요인의 효과가 다른 요인의 수준에 따라 달라지는가?
상호작용이 핵심 상호작용이 유의하면 주효과를 단독으로 해석하면 안 됩니다. "비료 효과는 물 주기에 따라 달라진다"처럼 조합 단위로 해석해야 합니다.

변동의 분해와 자유도

요인 A의 수준 a개, 요인 B의 수준 b개, 각 셀당 반복 n개일 때:

원천제곱합자유도
주효과 ASSAa − 1
주효과 BSSBb − 1
상호작용 A×BSSAB(a−1)(b−1)
오차(잔차)SSEab(n−1)
전체SSTN − 1

수치 예제 ②

비료(A1, A2) × 물 주기(B1, B2)의 2×2 설계, 각 조합당 2번 반복(총 8개)입니다. 균형 설계라 손계산이 깔끔합니다.

B1B2A 행평균
A16, 8  (x̄=7)10, 12  (x̄=11)9
A214, 16  (x̄=15)12, 14  (x̄=13)14
B 열평균111211.5 (전체)
  1. 전체제곱합 SST = Σ(x − 11.5)² = 78
  2. 주효과 A (SSA) = 4·(9−11.5)² + 4·(14−11.5)² = 25 + 25 = 50
  3. 주효과 B (SSB) = 4·(11−11.5)² + 4·(12−11.5)² = 1 + 1 = 2
  4. 상호작용 (SSAB) = Σ n·(셀평균 − A행평균 − B열평균 + 전체평균)²
    각 셀 편차 = ±1.5 → SSAB = 2·(1.5²×4) = 18
  5. 오차 (SSE) = SST − SSA − SSB − SSAB = 78 − 50 − 2 − 18 = 8
원천SSdfMSFp-value
비료 A5015025.0≈ 0.0075 ✔
물 주기 B2121.0≈ 0.374 ✘
상호작용 A×B181189.0≈ 0.040 ✔
오차842——
전체787———
결론 임계값 F0.05(1, 4) ≈ 7.71 기준으로 해석합니다.
  • 비료(A): F=25 > 7.71 → 유의
  • 물 주기(B): F=1 < 7.71 → 유의하지 않음
  • 상호작용(A×B): F=9 > 7.71 → 유의
상호작용이 유의하므로, 비료의 효과는 물 주기 수준에 따라 달라진다고 해석해야 합니다.

소스 예제 ②

이원분산분석은 statsmodels로 합니다. 공식(formula)에 :로 상호작용항을 명시합니다.

two_way_anova.py 
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols

df = pd.DataFrame({
    'growth': [6, 8, 10, 12, 14, 16, 12, 14],
    'fert'  : ['A1','A1','A1','A1','A2','A2','A2','A2'],
    'water' : ['B1','B1','B2','B2','B1','B1','B2','B2'],
})

# 주효과 2개 + 상호작용항 fert:water
model = ols('growth ~ C(fert) + C(water) + C(fert):C(water)', data=df).fit()
anova = sm.stats.anova_lm(model, typ=2)
print(anova)
#                   sum_sq   df     F    PR(>F)
# C(fert)             50.0  1.0  25.0  0.007490
# C(water)             2.0  1.0   1.0  0.373901
# C(fert):C(water)    18.0  1.0   9.0  0.039942
# Residual             8.0  4.0   NaN       NaN
Type 선택 위처럼 균형 설계(셀당 표본 수 동일)에서는 typ=1, 2, 3 결과가 같습니다. 불균형 설계에서만 달라지며, 상호작용이 없으면 typ=2, 있으면 typ=3을 권장합니다. (Type 3는 C(fert, Sum) 같은 합-대비 코딩 필요)

상호작용 시각화 코드

import matplotlib.pyplot as plt
from statsmodels.graphics.factorplots import interaction_plot

interaction_plot(x=df['water'], trace=df['fert'], response=df['growth'])
plt.title('Interaction Plot'); plt.show()
