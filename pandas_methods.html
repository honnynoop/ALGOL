공통 예제 데이터

아래 모든 예제는 이 한 개의 사원 DataFrame df를 기준으로 합니다.

코드

import pandas as pd
import numpy as np

df = pd.DataFrame({
    'dept'  : ['영업', '영업', '개발', '개발', '개발', '인사'],
    'name'  : ['김철수', '이영희', '박민수', '최지우', '정대현', '한소희'],
    'salary': [3200, 3500, 4100, 3900, 4500, 3000],
    'age'   : [28, 34, 41, 29, 38, 26],
    'grade' : ['B', 'A', 'A', 'C', 'A', 'B'],
})
df 
  dept name  salary  age grade
0   영업  김철수    3200   28     B
1   영업  이영희    3500   34     A
2   개발  박민수    4100   41     A
3   개발  최지우    3900   29     C
4   개발  정대현    4500   38     A
5   인사  한소희    3000   26     B
01

그룹 연산 — groupby

키를 기준으로 행을 묶어 그룹별 집계를 수행합니다. 분할(split) → 적용(apply) → 결합(combine) 패턴이 핵심입니다.

df.groupby()그룹화
하나 이상의 키로 행을 묶어 GroupBy 객체를 만들고, 집계 함수를 이어 붙입니다.
df.groupby(by, as_index=True, sort=True, dropna=True)

코드 — 부서별 평균 급여

df.groupby('dept')['salary'].mean()
결과 (Series) 
dept
개발    4166.666667
영업    3350.000000
인사    3000.000000
Name: salary, dtype: float64
tip · as_index=False를 주면 그룹 키가 인덱스가 아닌 일반 열로 남아 이후 처리가 편합니다. 여러 키는 groupby(['dept','grade'])처럼 리스트로 전달합니다.
df.agg()다중 집계
하나의 그룹에 여러 통계량을 한 번에 적용하고, 결과 열 이름까지 지정합니다.
grouped.agg(새이름=('열', '함수'), ...) # named aggregation

코드 — 부서별 여러 통계 한 번에

df.groupby('dept').agg(
    avg_salary=('salary', 'mean'),
    max_age   =('age',    'max'),
    count     =('name',   'count'),
)
결과 (DataFrame) 
       avg_salary  max_age  count
dept
개발    4166.666667       41      3
영업    3350.000000       34      2
인사    3000.000000       26      1
tip · 함수는 문자열('mean'), 함수 객체(np.std), 리스트(['min','max'])로도 줄 수 있습니다. named aggregation 방식이 열 이름을 깔끔하게 관리하는 가장 권장되는 형태입니다.
df.transform()길이 보존
그룹 집계 결과를 원본과 같은 행 개수로 되돌려 줍니다. 그룹 평균을 각 행 옆에 붙일 때 필수.
grouped.transform(func) → 입력과 동일한 shape 반환

코드 — 각 행에 소속 부서 평균 급여 붙이기

df['dept_avg'] = df.groupby('dept')['salary'].transform('mean')
df[['dept', 'salary', 'dept_avg']]
결과 
  dept  salary     dept_avg
0   영업    3200  3350.000000
1   영업    3500  3350.000000
2   개발    4100  4166.666667
3   개발    3900  4166.666667
4   개발    4500  4166.666667
5   인사    3000  3000.000000
agg vs transform · agg는 그룹당 1행으로 축소하고, transform은 행 수를 유지합니다. "그룹 평균 대비 편차" 같은 파생 변수를 만들 때는 transform.
df.groupby().apply()유연한 그룹 처리
그룹마다 임의의 함수(작은 DataFrame을 받는)를 적용합니다. "그룹별 상위 N개" 같은 작업에 강력.
grouped.apply(func, include_groups=False)

코드 — 부서별 최고 연봉자 1명씩

df.groupby('dept', group_keys=False).apply(
    lambda g: g.nlargest(1, 'salary'),
    include_groups=False
)
결과 
  name  salary  age grade
4  정대현    4500   38     A
1  이영희    3500   34     A
5  한소희    3000   26     B
성능 주의 · apply는 가장 유연하지만 가장 느립니다. 단순 집계는 agg, 길이 유지 변환은 transform을 먼저 고려하고, 정말 그룹 단위 복합 로직이 필요할 때만 apply를 쓰세요. (pandas 2.2+ 에서는 그룹 키 중복 경고를 피하려 include_groups=False 권장)
02

요소 · 조건 변환

행/열 단위 함수 적용, 값 매핑, 조건부 치환 등 데이터를 변형하는 핵심 도구들입니다.

df.apply()행/열 함수
axis=0이면 열 단위(각 열이 Series), axis=1이면 행 단위(각 행이 Series)로 함수를 적용합니다.
df.apply(func, axis=0) # axis=0: 열별 · axis=1: 행별

코드 ① — 열별 (max − min) 범위

df[['salary', 'age']].apply(lambda s: s.max() - s.min())
결과 (axis=0) 
salary    1500
age         15
dtype: int64

코드 ② — 행별 등급에 따른 보너스 계산

df['bonus'] = df.apply(
    lambda r: r['salary'] * 0.1 if r['grade'] == 'A' else r['salary'] * 0.05,
    axis=1
)
df[['name', 'grade', 'salary', 'bonus']]
결과 (axis=1) 
  name grade  salary  bonus
0  김철수     B    3200  160.0
1  이영희     A    3500  350.0
2  박민수     A    4100  410.0
3  최지우     C    3900  195.0
4  정대현     A    4500  450.0
5  한소희     B    3000  150.0
tip · 여러 열 조건을 조합하는 행 단위 로직엔 axis=1이 직관적이지만, 가능하면 벡터 연산(np.where, 산술 연산)으로 바꾸는 편이 훨씬 빠릅니다.
.map() / DataFrame.map()요소별 매핑
Series.map은 값을 사전/함수로 1:1 치환하고, DataFrame.map은 모든 셀에 함수를 적용합니다. (구 applymap 대체)
s.map(dict 또는 func) · df.map(func) # 모든 요소

코드 ① — 등급 코드 → 한글 라벨 (사전 매핑)

df['grade'].map({'A': '우수', 'B': '보통', 'C': '미흡'})
결과 
0    보통
1    우수
2    우수
3    미흡
4    우수
5    보통
Name: grade, dtype: str

코드 ② — 모든 셀에 함수 적용 (DataFrame.map)

df[['salary', 'age']].map(lambda x: x * 2).head(3)
결과 
   salary  age
0    6400   56
1    7000   68
2    8200   82
구분 · map(Series, 요소별) · apply(Series는 요소별 / DataFrame은 행·열별) · DataFrame.map(모든 셀). pandas 2.1부터 applymap은 DataFrame.map으로 이름이 바뀌었습니다.
.where() / .mask()조건부 치환
조건에 따라 값을 유지하거나 다른 값으로 바꿉니다. 둘은 정확히 반대로 동작합니다.
s.where(cond, other) # cond=False인 곳 치환 · s.mask(cond, other) # cond=True인 곳 치환

코드 ① — where: 3500 미만이면 0으로

df['salary'].where(df['salary'] >= 3500, other=0)
결과 (조건 False → 치환) 
0       0
1    3500
2    4100
3    3900
4    4500
5       0
Name: salary, dtype: int64

코드 ② — mask: 3500 이상이면 9999로

df['salary'].mask(df['salary'] >= 3500, other=9999)
결과 (조건 True → 치환) 
0    3200
1    9999
2    9999
3    9999
4    9999
5    3000
Name: salary, dtype: int64
기억법 · where = "조건이 참인 곳은 그대로 둔다(where it's true, keep)". mask = "조건이 참인 곳을 가린다(mask = 덮어쓴다)".
df.query()문자열 필터
불리언 인덱싱을 SQL 비슷한 문자열 식으로 표현합니다. 가독성이 좋고 @변수로 외부 값도 참조 가능.
df.query("조건식 문자열") # and/or, ==, in, @변수 사용 가능

코드 — 급여 3500 이상 & 나이 40 미만

df.query("salary >= 3500 and age < 40")
결과 
  dept name  salary  age grade
1   영업  이영희    3500   34     A
3   개발  최지우    3900   29     C
4   개발  정대현    4500   38     A
tip · df.query("dept in ['영업','인사']"), df.query("salary > @threshold")처럼 멤버십·외부 변수도 가능합니다. 같은 결과를 불리언 인덱싱 df[(df.salary>=3500)&(df.age<40)]로도 쓸 수 있습니다.
df.assign()파생 열 · 체이닝
원본을 바꾸지 않고 새 열을 추가한 복사본을 반환합니다. 메서드 체이닝에 최적.
df.assign(새열=값 또는 lambda d: 식) → 새 DataFrame 반환

코드 — 지방소득세(3.3%) 열 추가

df.assign(tax=lambda d: (d['salary'] * 0.033).round(1))[['name', 'salary', 'tax']]
결과 
  name  salary    tax
0  김철수    3200  105.6
1  이영희    3500  115.5
2  박민수    4100  135.3
3  최지우    3900  128.7
4  정대현    4500  148.5
5  한소희    3000   99.0
tip · lambda d: ...를 쓰면 같은 호출 안에서 막 만든 열을 곧바로 참조할 수 있어 df.assign(a=...).assign(b=...) 식의 깔끔한 파이프라인을 만들 수 있습니다.
03

재구조화 · 결합

긴 형태(long)와 넓은 형태(wide)를 오가고, 여러 테이블을 합치는 도구들입니다.

pd.pivot_table()교차 집계
행·열 두 축으로 값을 집계하는 엑셀 피벗테이블. 중복 키가 있어도 aggfunc로 요약합니다.
pd.pivot_table(df, values, index, columns, aggfunc='mean')

코드 — 부서 × 등급별 평균 급여

pd.pivot_table(df, values='salary', index='dept', columns='grade', aggfunc='mean')
결과 
grade       A       B       C
dept
개발     4300.0     NaN  3900.0
영업     3500.0  3200.0     NaN
인사        NaN  3000.0     NaN
pivot vs pivot_table · pivot은 단순 reshape라 중복 인덱스가 있으면 에러가 납니다. 집계가 필요하면 항상 pivot_table. 결측 칸은 fill_value=0으로 채울 수 있습니다.
df.melt()wide → long
여러 열을 두 개의 열(변수명, 값)로 녹여 긴 형태(tidy data)로 바꿉니다. pivot의 역연산.
df.melt(id_vars, value_vars, var_name, value_name)

코드 — 과목 점수를 long 포맷으로

wide = pd.DataFrame({'name': ['A', 'B'], 'kor': [90, 80], 'eng': [85, 95]})
wide.melt(id_vars='name', var_name='subject', value_name='score')
결과 
  name subject  score
0    A     kor     90
1    B     kor     80
2    A     eng     85
3    B     eng     95
tip · 머신러닝·시각화(seaborn 등)는 대부분 long 포맷을 선호합니다. id_vars는 그대로 유지할 식별 열, 나머지가 녹는 대상입니다.
pd.crosstab()빈도 교차표
두 범주형 변수의 교차 빈도(분할표)를 만듭니다. 카이제곱 검정 전처리로 자주 쓰입니다.
pd.crosstab(index, columns, normalize=False, margins=False)

코드 — 부서 × 등급 빈도

pd.crosstab(df['dept'], df['grade'])
결과 
grade  A  B  C
dept
개발     2  0  1
영업     1  1  0
인사     0  1  0
tip · normalize='index'로 행 기준 비율, margins=True로 합계 행/열을 추가합니다. 빅분기/ADP 카이제곱 독립성 검정에서 scipy.stats.chi2_contingency(pd.crosstab(...)) 형태로 자주 등장합니다.
pd.merge() / pd.concat()테이블 결합
merge는 키 기준 SQL 조인, concat은 축 방향 단순 이어붙이기입니다.
df.merge(other, on, how='inner'|'left'|'right'|'outer')

코드 — 부서별 층 정보 left join

floor = pd.DataFrame({'dept': ['영업', '개발', '인사'], 'floor': [3, 5, 2]})
df.merge(floor, on='dept', how='left')[['name', 'dept', 'floor']].head(3)
결과 
  name dept  floor
0  김철수   영업      3
1  이영희   영업      3
2  박민수   개발      5
merge vs concat · merge = 공통 키로 가로 결합(조인). concat([a, b]) = 행을 세로로, concat([a, b], axis=1) = 열을 가로로 단순 결합. 키 매칭이 필요 없으면 concat이 가볍습니다.
04

정렬 · 집계 · 정제

정렬, 빈도 집계, 열 선택, 결측 처리 — 분석 전후로 늘 쓰는 기본기입니다.

df.sort_values()값 정렬
하나 이상의 열을 기준으로 정렬합니다. 키마다 오름/내림차순을 따로 지정할 수 있습니다.
df.sort_values(by, ascending=True, na_position='last')

코드 — 부서 오름차순, 급여 내림차순

df.sort_values(['dept', 'salary'], ascending=[True, False])
결과 
  dept name  salary  age grade
4   개발  정대현    4500   38     A
2   개발  박민수    4100   41     A
3   개발  최지우    3900   29     C
1   영업  이영희    3500   34     A
0   영업  김철수    3200   28     B
5   인사  한소희    3000   26     B
tip · 인덱스 기준 정렬은 sort_index(). 상위 N개만 빠르게 뽑을 땐 정렬 대신 df.nlargest(3, 'salary') / nsmallest가 더 효율적입니다.
.value_counts()빈도 집계
고유값별 등장 횟수를 내림차순으로 셉니다. 범주형 변수 탐색의 1순위 도구.
s.value_counts(normalize=False, sort=True, dropna=True)

코드 — 부서별 인원수

df['dept'].value_counts()
결과 
dept
개발    3
영업    2
인사    1
Name: count, dtype: int64
tip · normalize=True를 주면 횟수 대신 비율을 반환합니다. 구간별 분포가 필요하면 pd.cut으로 묶은 뒤 value_counts(sort=False)를 씁니다.
df.filter()라벨 선택
행/열을 이름 패턴으로 선택합니다. 값 조건 필터가 아니라 라벨 기준이라는 점이 중요.
df.filter(items=, like=, regex=, axis=)

코드 — 이름에 '2021'이 들어간 열만

df2 = pd.DataFrame({'2021_sales': [1, 2], '2022_sales': [3, 4], '2021_cost': [5, 6]})
df2.filter(like='2021')
결과 
   2021_sales  2021_cost
0           1          5
1           2          6
주의 · filter는 데이터 값이 아니라 인덱스/열 이름에만 작동합니다. 값 조건으로 행을 거르려면 query나 불리언 인덱싱을 쓰세요. regex='sales$'처럼 정규식도 가능합니다.
.fillna() / .dropna()결측 처리
결측치(NaN)를 특정 값으로 채우거나, 결측이 있는 행/열을 제거합니다.
df.fillna(value) · df.dropna(axis=0, how='any', subset=)

코드

nadf = pd.DataFrame({'x': [1, np.nan, 3], 'y': [np.nan, 2, 3]})
nadf.fillna(0)   # 결측을 0으로
nadf.dropna()    # 결측 있는 행 제거
fillna(0) 
     x    y
0  1.0  0.0
1  0.0  2.0
2  3.0  3.0
dropna() 
     x    y
2  3.0  3.0
tip · 평균/중앙값 대치는 df['x'].fillna(df['x'].mean()). 특정 열에 결측이 있을 때만 행을 지우려면 dropna(subset=['x']). 결측 위치 확인은 df.isna().sum().

한눈에 정리 — 비교 치트시트

헷갈리기 쉬운 메서드들의 차이를 한 표로 정리했습니다.

구분메서드입력 → 출력언제 쓰나
그룹 적용agg그룹 → 그룹당 1행 (축소)부서별 평균·합계 등 요약 통계
transform그룹 → 원본과 같은 행 수그룹 평균을 각 행에 붙여 파생변수 생성
apply그룹(작은 DataFrame) → 자유그룹별 상위 N개 등 복합 로직 (느림)
요소 적용Series.map값 → 값 (1:1)사전/함수로 코드 → 라벨 치환
Series.apply값 → 값요소별 사용자 함수 (map보다 유연)
DataFrame.map모든 셀 → 셀전체 셀에 동일 함수 (구 applymap)
조건 치환where(cond)cond False인 곳 치환"조건 만족하는 값만 남기고 나머지 대체"
mask(cond)cond True인 곳 치환"조건 만족하는 값을 덮어쓰기"
행 선택query("식")값 조건 → 행 필터가독성 좋은 복합 조건 필터링
filter(like=)이름 패턴 → 행/열 선택열 이름 기준 선택 (값 무관)
재구조화pivot_tablelong → wide (집계)행×열 교차 집계표
meltwide → long여러 열을 변수/값 두 열로 녹이기
결합merge키 기준 가로 결합SQL JOIN — 공통 키로 테이블 합치기
concat축 방향 이어붙이기같은 구조 데이터를 위/옆으로 누적
선택 가이드 · 그룹 요약이면 agg → 파생변수면 transform → 그래도 안 되면 apply. 조건 필터는 query, 조건 치환은 where/mask, 값 매핑은 map. 구조를 바꾸려면 pivot_table↔melt, 합치려면 merge(키)/concat(축). 성능이 중요하면 apply·axis=1보다 벡터 연산을 먼저 떠올리세요.
