💡 결과 해석

📈 강한 성장 추세: 1949년 월평균 150명 → 1960년 430명. 12년간 약 3배 성장. 항공 대중화 시대 반영.
☀️ 계절성 패턴: 7~8월(여름)이 연중 최고 성수기. 1~2월(겨울)이 비수기. 매년 반복되는 U자형 패턴.
📊 곱셈적 계절성: 시간이 지날수록 계절 진폭도 커짐 → 로그 변환 후 SARIMA 모델 적합.
🔮 예측 활용: 항공사 운항 계획, 인력 배치, 수요 예측에 직접 활용 가능한 패턴.

💻 실행 코드

import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# 데이터 로드
flights = sns.load_dataset('flights')
print(flights.head())

# 피벗 테이블 (히트맵용)
pivot = flights.pivot(index='month', columns='year', values='passengers')

# 히트맵
plt.figure(figsize=(12, 5))
sns.heatmap(pivot, annot=True, fmt='d', cmap='YlOrRd', linewidths=0.3)
plt.title('항공 승객 수 히트맵')
plt.tight_layout(); plt.show()

# 시계열 시각화
fig, axes = plt.subplots(2, 1, figsize=(12, 8))
# 전체 시계열
ts = flights.groupby('year')['passengers'].sum()
axes[0].plot(ts.index, ts.values, marker='o')
axes[0].set_title('연간 총 승객 수')

# 계절성 (월별 평균)
month_avg = flights.groupby('month')['passengers'].mean()
axes[1].bar(range(12), month_avg.values)
axes[1].set_xticks(range(12))
axes[1].set_xticklabels(month_avg.index, rotation=45)
axes[1].set_title('월별 평균 승객 수 (계절성)')
plt.tight_layout(); plt.show()
