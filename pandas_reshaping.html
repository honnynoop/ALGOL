00

long vs wide 개념

재구조화는 결국 long(좁고 긴) ↔ wide(넓고 짧은) 두 형태를 오가는 일입니다. 어느 방향으로 가는지가 메서드 선택의 기준입니다.

long→wide: pivot · pivot_table · unstack  |  wide→long: melt · stack
방향 + 집계 + 인덱스가 메서드를 가릅니다. long→wide 중 집계가 필요하면 pivot_table, 단순 재배치면 pivot. 인덱스 기반으로 다루면 stack/unstack, 일반 열 기반이면 melt/pivot입니다.
01

기본 데이터

import pandas as pd, numpy as np

df = pd.DataFrame({
    'dept'   :['영업','영업','개발','개발','개발','개발'],
    'quarter':['Q1','Q2','Q1','Q2','Q1','Q2'],
    'name'   :['김','김','이','이','박','박'],
    'sales'  :[100,120,90,150,80,110],
})
df (long 형태) 
  dept quarter name  sales
0   영업      Q1    김    100
1   영업      Q2    김    120
2   개발      Q1    이     90
3   개발      Q2    이    150
4   개발      Q1    박     80
5   개발      Q2    박    110
02

long → wide 변환

df.pivot()long → wide
index·columns·values를 지정해 단순 재배치합니다. 집계하지 않으므로 같은 (index, columns) 조합이 중복되면 에러납니다.
df.pivot(index='name', columns='quarter', values='sales')
결과 
quarter   Q1   Q2
name
김        100  120
박         80  110
이         90  150
주의 · pivot은 (index, columns) 쌍이 유일해야 합니다. 중복이 있으면 ValueError: Index contains duplicate entries. 중복을 합쳐야 하면 pivot_table을 쓰세요.
pd.pivot_table()long → wide
엑셀 피벗테이블. 중복 키를 aggfunc로 집계하고, margins로 합계 행/열을 추가합니다.
pd.pivot_table(df, index='dept', columns='quarter', values='sales',
               aggfunc='sum', margins=True)        # margins=합계 추가
결과 
quarter   Q1   Q2  All
dept
개발       170  260  430
영업       100  120  220
All      270  380  650
tip · aggfunc는 'mean'·'count'·리스트(['sum','mean'])도 가능. 빈 칸은 fill_value=0. pivot은 재배치, pivot_table은 집계가 핵심 차이입니다.
df.unstack()long → wide
MultiIndex의 한 레벨을 열로 올립니다. groupby 결과(인덱스 기반)를 표로 펼칠 때 유용합니다.
p = df.pivot_table(index=['dept','name'], columns='quarter', values='sales')
p.unstack(level=0)          # dept(레벨0)를 열로 올림
p.unstack(level='dept')     # 이름으로도 지정 가능
p.unstack(level=0) 
quarter    Q1            Q2
dept       개발     영업    개발     영업
name
김         NaN  100.0    NaN  120.0
박        80.0    NaN  110.0    NaN
이        90.0    NaN  150.0    NaN
pivot_table과 차이 · 결과는 비슷하지만 unstack은 이미 인덱스에 있는 레벨을 열로 옮깁니다. groupby로 만든 MultiIndex Series/DataFrame에 바로 적용하기 좋습니다.
03

wide → long 변환

df.melt()wide → long
여러 열을 (변수명, 값) 두 열로 녹입니다. pivot의 역연산이며 tidy 데이터를 만드는 표준 방법.
wide = df.pivot(index='name', columns='quarter', values='sales').reset_index()
wide.melt(id_vars='name', var_name='quarter', value_name='sales')
결과 
  name quarter  sales
0    김      Q1    100
1    박      Q1     80
2    이      Q1     90
3    김      Q2    120
4    박      Q2    110
5    이      Q2    150
tip · id_vars는 그대로 유지할 식별 열, 나머지가 녹는 대상입니다. seaborn 등 시각화·ML 입력은 대부분 long(tidy) 포맷을 선호합니다.
df.stack()wide → long
열 라벨을 인덱스 안쪽으로 내려 Series(long)로 만듭니다. unstack의 역연산.
p = df.pivot_table(index=['dept','name'], columns='quarter', values='sales')
p.stack()                    # quarter 열을 인덱스로 내림
p.stack().unstack()          # 왕복 → 원래대로
p.stack() 
dept  name  quarter
개발    박     Q1          80.0
            Q2         110.0
      이     Q1          90.0
            Q2         150.0
영업    김     Q1         100.0
            Q2         120.0
dtype: float64
melt vs stack · 둘 다 wide→long이지만, melt는 일반 열을 기준으로 동작하고 stack은 (Multi)Index/열 라벨을 기준으로 동작합니다. 인덱스 구조를 살려야 하면 stack, 평범한 표를 녹이면 melt가 직관적입니다.
04

기타 변환

pd.crosstab()빈도표
두 범주형의 교차 빈도(분할표)를 만듭니다. 기본은 개수를 세며, 정규화·합계 옵션이 있습니다.
pd.crosstab(df['dept'], df['quarter'])                    # 빈도
pd.crosstab(df['dept'], df['quarter'], normalize='index') # 행 기준 비율
pd.crosstab(df['dept'], df['quarter'], margins=True)      # 합계 추가
crosstab (빈도 / 행 정규화) 
quarter  Q1  Q2        quarter   Q1   Q2
dept               →  dept
개발        2   2        개발       0.5  0.5
영업        1   1        영업       0.5  0.5
tip · values=와 aggfunc=를 주면 빈도 대신 집계도 가능해 pivot_table과 비슷해집니다. 카이제곱 독립성 검정 전처리로 자주 쓰입니다: chi2_contingency(pd.crosstab(...)).
df.explode()리스트 → 행
셀에 들어있는 리스트(또는 배열)를 여러 행으로 펼칩니다. 한 칸에 여러 값이 든 데이터를 정규화할 때.
e = pd.DataFrame({'name':['김','이'], 'skills':[['py','sql'], ['java']]})
e.explode('skills')
결과 
  name skills
0    김     py
0    김    sql
1    이   java
tip · 인덱스가 중복되니 필요하면 .reset_index(drop=True). 문자열이라면 먼저 df['col'].str.split(',')로 리스트를 만든 뒤 explode하는 패턴이 흔합니다.
pd.get_dummies()범주 → 원핫
범주형 변수를 0/1 더미 열로 펼칩니다(원핫 인코딩). ML 모델 입력 전처리의 핵심.
pd.get_dummies(df['dept'], prefix='dept').astype(int)
# 다중공선성 방지: 첫 범주 제거
pd.get_dummies(df, columns=['dept','quarter'], drop_first=True)
결과 
   dept_개발  dept_영업
0        0        1
1        0        1
2        1        0
tip · 회귀처럼 다중공선성에 민감한 모델은 drop_first=True로 한 범주를 빼는 게 좋습니다(트리 모델은 무관). 기본 출력은 bool이라 필요시 .astype(int). 역변환은 pd.from_dummies().
05

선택 가이드

하고 싶은 것메서드방향집계
긴 표를 교차표로 (중복 없음)pivotlong→wide✕
긴 표를 집계 교차표로pivot_tablelong→wide○
MultiIndex 레벨을 열로unstacklong→wide✕
여러 열을 변수/값으로 녹이기meltwide→long✕
열 라벨을 인덱스로 내리기stackwide→long✕
두 범주 빈도 교차표crosstab—○(개수)
리스트 셀을 행으로explode—✕
범주를 0/1 열로 (원핫)get_dummies—✕
3가지 질문으로 결정 · ① 방향은? (long→wide면 pivot류, 반대면 melt/stack) · ② 집계가 필요한가? (필요하면 pivot_table) · ③ 인덱스 기반인가 일반 열 기반인가? (인덱스면 stack/unstack, 열이면 melt/pivot). 이 셋이면 거의 모든 재구조화를 고를 수 있습니다.
