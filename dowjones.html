💡 결과 해석

💥 대공황(1929~1933): 지수 90% 폭락 — 역사상 최악의 주가 붕괴. 수익률 분포의 극단적 왼쪽 꼬리.
📈 전후 호황(1950s~1960s): 2차 세계대전 이후 경제 성장 반영, 지수 꾸준한 상승.
📊 수익률 분포: 정규분포에 가깝지만 두꺼운 꼬리(fat tail) — 극단적 사건의 빈도가 정규분포보다 높음.
📉 변동성 클러스터링: 높은 변동성 시기가 연속됨 — GARCH 모델 적합의 전형적 특성.

💻 실행 코드

import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# 데이터 로드
df = sns.load_dataset('dowjones')
df['Date'] = pd.to_datetime(df['Date'])

# 수익률 계산
df['Return'] = df['Price'].pct_change() * 100
df['LogReturn'] = np.log(df['Price'] / df['Price'].shift(1)) * 100

# 이동평균
df['MA12'] = df['Price'].rolling(12).mean()
df['MA60'] = df['Price'].rolling(60).mean()

# 기본 통계
print("월간 수익률 통계:")
print(df['Return'].describe())
print(f"왜도: {df['Return'].skew():.3f}")
print(f"첨도: {df['Return'].kurtosis():.3f}")

# 시각화
fig, axes = plt.subplots(3, 1, figsize=(14, 10))
axes[0].plot(df['Date'], df['Price'], label='지수')
axes[0].plot(df['Date'], df['MA12'], 'r--', label='MA12')
axes[0].set_title('다우존스 지수')
axes[0].legend()

axes[1].bar(df['Date'], df['Return'],
            color=['red' if r < 0 else 'green' for r in df['Return']])
axes[1].set_title('월간 수익률')

axes[2].plot(df['Date'], df['Return'].rolling(12).std())
axes[2].set_title('12개월 롤링 변동성')

plt.tight_layout(); plt.show()
