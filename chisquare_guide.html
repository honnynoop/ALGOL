관측도수와 기대도수의 차이로 범주형 변수의 분포·연관성을 검정하는 방법 — 수학적 배경부터 수치 예제, Python 구현, 사후분석까지

적합도 χ² = 4.5 독립성 χ² = 11.67 동질성 χ² = 4.57
개념

카이제곱 검정이란?

카이제곱($\chi^2$) 검정은 범주형(categorical) 자료에서 우리가 실제로 관측한 빈도(관측도수 O, Observed)가, 어떤 가설 아래 이론적으로 기대되는 빈도(기대도수 E, Expected)와 얼마나 차이 나는지를 측정하는 비모수적 검정입니다. 1900년 칼 피어슨(Karl Pearson)이 제안하여 피어슨 카이제곱 통계량이라고도 부릅니다.

$$ \chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i} $$

각 칸에서 "관측 − 기대" 편차를 제곱하여 기대도수로 나눈 뒤 모두 더합니다. 편차를 제곱하므로 부호가 사라지고, 기대도수로 나누므로 같은 크기의 편차라도 기대도수가 작은 칸에서 더 큰 기여를 합니다. 차이가 클수록 $\chi^2$ 값이 커지고, 그 값이 임계값을 넘으면 "우연으로 보기 어렵다"며 귀무가설을 기각합니다.

왜 평균이 아니라 빈도(도수)인가? $t$-검정·분산분석이 연속형 변수의 평균을 비교한다면, 카이제곱은 "어느 범주에 몇 개가 들어갔는가"라는 빈도 자체를 다룹니다. 그래서 비율(%)이 아닌 실제 개수(count)로 계산해야 합니다.
분포

카이제곱 분포의 수학적 배경

표준정규분포를 따르는 독립 확률변수 $Z_1, Z_2, \dots, Z_k$가 있을 때, 그 제곱합이 따르는 분포가 자유도 $k$인 카이제곱 분포입니다. 피어슨 통계량이 근사적으로 이 분포를 따르기 때문에 "카이제곱 검정"이라 부릅니다.

$$ Q = \sum_{i=1}^{k} Z_i^2 \ \sim\ \chi^2(k), \qquad Z_i \overset{iid}{\sim} N(0,1) $$

확률밀도함수 (PDF)

$$ f(x;k) = \frac{1}{2^{k/2}\,\Gamma\!\left(\tfrac{k}{2}\right)}\, x^{\,k/2-1}\, e^{-x/2}, \qquad x > 0 $$

여기서 $\Gamma(\cdot)$는 감마함수입니다. 카이제곱 분포는 사실 형상모수 $k/2$, 척도모수 $2$인 감마분포의 특수한 경우입니다.

주요 성질

특성값 / 설명
정의역$x \ge 0$ (음수 불가 — 제곱합이므로)
평균 $E[X]$$k$ (자유도)
분산 $Var[X]$$2k$
최빈값(mode)$\max(k-2,\ 0)$
왜도(skewness)$\sqrt{8/k}$ — 우측으로 치우침, $k$↑이면 0에 수렴
가법성$\chi^2(k_1)+\chi^2(k_2)=\chi^2(k_1+k_2)$ (독립일 때)

자유도에 따른 분포 모양

분포의 특징 카이제곱 분포는 0 이상의 값만 가지며 오른쪽으로 치우친(우측 비대칭) 형태입니다. 자유도(df)가 작으면 0 근처에 몰려 급격히 꺾이고($k\le2$), df가 커질수록 봉우리가 오른쪽으로 이동하며 점점 종 모양(정규분포)에 가까워집니다. 검정은 항상 우측 단측검정으로, $\chi^2$이 임계값보다 크면 기각합니다.

절차

검정의 일반 절차

  1. 가설 설정 — $H_0$: 분포가 이론과 일치한다 / 변수가 독립이다. $H_1$: 그렇지 않다.
  2. 기대도수 $E$ 계산 — $H_0$가 참이라고 가정했을 때 각 칸의 기대 빈도를 구합니다.
  3. 검정통계량 계산 — $\chi^2 = \sum (O-E)^2/E$.
  4. 자유도 결정 — 검정 유형에 따라 $df$를 구합니다.
  5. 판정 — $\chi^2 > \chi^2_\alpha(df)$ 이거나 $p\text{-value} < \alpha$ 이면 $H_0$ 기각.
기대도수가 핵심 카이제곱 검정의 모든 차이는 결국 "기대도수를 어떻게 정의하느냐"에서 출발합니다. 적합도는 이론 확률 × 표본 크기, 분할표(독립성·동질성)는 (행 합 × 열 합) / 총합으로 기대도수를 만듭니다.
유형

세 가지 검정 유형

① 적합도 검정

Goodness of Fit

한 변수의 관측 분포가 특정 이론 분포(예: 균등·정규)와 맞는가?

df = (범주 수) − 1 − (추정한 모수 개수)

② 독립성 검정

Test of Independence

한 표본에서 측정한 두 변수가 서로 연관되어 있는가?

df = (행−1)(열−1)

③ 동질성 검정

Test of Homogeneity

여러 모집단의 범주 분포가 서로 같은가(동질한가)?

df = (행−1)(열−1)

②와 ③의 차이 계산식과 자유도는 완전히 동일합니다. 차이는 표본 추출 설계에 있습니다. 독립성은 하나의 표본에서 두 변수를 동시에 측정하고, 동질성은 각 집단(모집단)별로 표본 크기를 미리 고정해 뽑은 뒤 분포를 비교합니다.
예제 ①

적합도 검정 — 주사위는 공정한가?

주사위를 120번 던졌습니다. 공정하다면 각 눈은 $120/6 = 20$회 나와야 합니다.

$$ H_0:\ \text{각 눈이 나올 확률이 모두 } \tfrac{1}{6} \quad\text{vs}\quad H_1:\ \text{적어도 하나는 다름} $$
눈123456합
관측 O162418252215120
기대 E202020202020120
$(O-E)^2/E$0.800.800.201.250.201.254.50
$$ \chi^2 = \frac{(-4)^2}{20}+\frac{4^2}{20}+\frac{(-2)^2}{20}+\frac{5^2}{20}+\frac{2^2}{20}+\frac{(-5)^2}{20} = 4.5 $$

자유도: $df = 6 - 1 = 5$  ·  임계값: $\chi^2_{0.05}(5) = 11.07$  ·  p-value $= 0.480$

기각역과 검정통계량의 위치

검정통계량 4.5는 채택역(임계값 왼쪽)에 위치 → 귀무가설 기각 못함

Python 구현 — scipy.stats.chisquare

goodness_of_fit.pyPython
import numpy as np
from scipy import stats

# 관측도수와 기대도수 (합이 같아야 함)
observed = np.array([16, 24, 18, 25, 22, 15])
expected = np.full(6, observed.sum() / 6)   # 공정하다면 각 20회

chi2, p = stats.chisquare(f_obs=observed, f_exp=expected)
df = len(observed) - 1
crit = stats.chi2.ppf(0.95, df)             # 우측 5% 임계값

print(f"chi2 = {chi2:.4f}")
print(f"df   = {df}")
print(f"crit(0.05) = {crit:.4f}")
print(f"p-value = {p:.4f}")
print("결론:", "기각" if p < 0.05 else "기각 못함")
OUTPUTchi2 = 4.5000 df = 5 crit(0.05) = 11.0705 p-value = 0.4799 결론: 기각 못함
결론 $\chi^2 = 4.5 < 11.07$ 이고 $p = 0.48 > 0.05$ 이므로 귀무가설을 기각하지 못합니다. 즉, 관측된 차이는 우연의 범위 안이며 주사위가 공정하지 않다는 증거는 없습니다.

import numpy as np
from scipy import stats

# 분할표 (행: 성별, 열: 음료)
table = np.array([[40, 30, 30],    # 남자
                  [20, 50, 30]])   # 여자

chi2, p, dof, expected = stats.chi2_contingency(table, correction=False)

print("기대도수 E =")

print(f"chi2 = {chi2:.4f},  df = {dof},  p = {p:.4f}")

효과크기

효과크기 — 연관이 "얼마나" 강한가?

$p$-값은 "연관이 있는가(유무)"만 알려줄 뿐, 표본이 커지면 작은 차이도 유의해집니다. 연관의 크기를 보려면 효과크기를 함께 보고해야 합니다.

Cramér's V (분할표용)

$$ V = \sqrt{\frac{\chi^2}{N\,(k-1)}}, \qquad k = \min(\text{행 수},\ \text{열 수}) $$

$2\times2$ 표에서는 $\phi$(파이) 계수와 같습니다($\phi=\sqrt{\chi^2/N}$). $V$는 $0$(무관)에서 $1$(완전 연관) 사이 값을 가집니다.

df* = min(행,열)−1작음(small)중간(medium)큼(large)
10.100.300.50
20.070.210.35
30.060.170.29

* Cohen(1988) 기준. 예제 ②(독립성)는 $k=2$이므로 df*=1 기준을 적용합니다.

effect_size.pyPython
import numpy as np
from scipy import stats

table = np.array([[40, 30, 30], [20, 50, 30]])  # 예제 ②
chi2, p, dof, _ = stats.chi2_contingency(table, correction=False)

n = table.sum()
k = min(table.shape)
cramers_v = np.sqrt(chi2 / (n * (k - 1)))
print(f"Cramer's V = {cramers_v:.4f}")   # 0.2415 → 작음~중간

# scipy 1.7+ 에서는 내장 함수도 제공
res = stats.contingency.association(table, method="cramer")
print(f"association = {res:.4f}")
OUTPUTCramer's V = 0.2415 association = 0.2415
해석 예제 ②의 $V=0.24$는 df*=1 기준에서 작음~중간 정도의 연관입니다. 즉 성별과 음료 선호는 통계적으로 유의하지만, 실질적 연관의 크기는 강하지 않습니다. 예제 ③(동질성)의 $V=0.15$는 더 약하며 유의하지도 않았습니다.
사후검정

잔차분석 — 어느 칸이 차이를 만들었나?

전체 검정이 유의해도 "어느 칸 때문에 유의했는가"는 따로 봐야 합니다. 조정된 표준화 잔차(adjusted standardized residual)를 쓰면 각 칸을 표준정규처럼 해석할 수 있어, 절댓값이 1.96을 넘으면 그 칸이 유의하게 기여했다고 판단합니다.

$$ r_{ij} = \frac{O_{ij}-E_{ij}}{\sqrt{E_{ij}\left(1-\dfrac{n_{i\cdot}}{N}\right)\!\left(1-\dfrac{n_{\cdot j}}{N}\right)}} $$

분자는 단순 표준화 잔차 $(O-E)/\sqrt{E}$이고, 분모의 행·열 비율 보정이 들어가야 정확히 $N(0,1)$을 따릅니다. 예제 ②에 적용한 결과입니다.

조정된 표준화 잔차 — |값|>1.96(점선 밖)이면 유의. 커피·차 칸이 차이를 만듦

residuals.pyPython
import numpy as np
from scipy import stats

table = np.array([[40, 30, 30], [20, 50, 30]])
chi2, p, dof, E = stats.chi2_contingency(table, correction=False)

n = table.sum()
row = table.sum(axis=1, keepdims=True)   # 행 합
col = table.sum(axis=0, keepdims=True)   # 열 합

# 조정된 표준화 잔차
adj = (table - E) / np.sqrt(E * (1 - row / n) * (1 - col / n))
print(np.round(adj, 2))

# |잔차| > 1.96 인 칸이 유의하게 기여
sig = np.abs(adj) > 1.96
print("유의 셀 위치:\n", sig)
OUTPUT[[ 3.09 -2.89 0. ] [-3.09 2.89 0. ]] 유의 셀 위치: [[ True True False] [ True True False]]
해석 커피(남자 +3.09, 여자 −3.09)와 차(남자 −2.89, 여자 +2.89) 칸의 잔차가 ±1.96을 넘습니다. 남자는 커피를 기대보다 많이, 여자는 차를 기대보다 많이 선호하는 것이 전체 유의성의 원인입니다. 주스는 두 집단 모두 기대치와 차이가 없습니다.
주의

가정 & 주의사항

항목내용
기대도수 조건모든 칸의 기대도수 $E_i \ge 5$ 권장(전체의 80% 이상이 5 이상, 어떤 칸도 1 미만 아님). 작은 칸이 많으면 검정이 부정확해짐 → Fisher 정확검정 고려
2×2 보정$2\times2$ 표에서 표본이 작으면 Yates 연속성 보정 적용: $\displaystyle\sum\frac{(|O-E|-0.5)^2}{E}$  (scipy는 기본값 correction=True)
독립 관측각 관측치는 서로 독립이어야 하며, 한 개체가 한 칸에만 속해야 함(반복측정 ✗ → McNemar 검정)
도수 사용비율(%)이 아닌 실제 빈도(count)로 계산해야 함
단측 성격항상 우측 기각역만 사용(차이의 크기만 보고 방향은 따지지 않음)
표본 크기 민감성$N$이 매우 크면 사소한 차이도 유의해짐 → 반드시 효과크기(Cramér's V) 병기

chi_square_report.pyPython
import numpy as np
from scipy import stats


def chi_square_gof(observed, expected=None):
    """적합도 검정 (Goodness of Fit)."""
    observed = np.asarray(observed, dtype=float)
    if expected is None:                       # 기본: 균등분포 가정
        expected = np.full_like(observed, observed.sum() / len(observed))
    chi2, p = stats.chisquare(observed, expected)
    df = len(observed) - 1
    return {
        "chi2": chi2, "df": df, "p": p,
        "crit_0.05": stats.chi2.ppf(0.95, df),
        "reject_H0": p < 0.05,
    }


def chi_square_table(table, correction=False):
    """독립성/동질성 검정 + 효과크기 + 조정 잔차를 한 번에."""
    table = np.asarray(table, dtype=float)
    chi2, p, dof, E = stats.chi2_contingency(table, correction=correction)

    n = table.sum()
    k = min(table.shape)
    cramers_v = np.sqrt(chi2 / (n * (k - 1)))

    row = table.sum(axis=1, keepdims=True)
    col = table.sum(axis=0, keepdims=True)
    adj_resid = (table - E) / np.sqrt(E * (1 - row / n) * (1 - col / n))

    return {
        "chi2": chi2, "df": dof, "p": p,
        "crit_0.05": stats.chi2.ppf(0.95, dof),
        "cramers_v": cramers_v,
        "expected": E,
        "adj_residuals": adj_resid,
        "significant_cells": np.abs(adj_resid) > 1.96,
        "reject_H0": p < 0.05,
    }


if __name__ == "__main__":
    # 예제 ① 적합도
    print("[적합도]", chi_square_gof([16, 24, 18, 25, 22, 15]))

    # 예제 ② 독립성
    res = chi_square_table([[40, 30, 30], [20, 50, 30]])
    print(f"[독립성] chi2={res['chi2']:.3f}, p={res['p']:.4f}, "
          f"V={res['cramers_v']:.3f}, reject={res['reject_H0']}")
    print("조정 잔차:\n", np.round(res["adj_residuals"], 2))
OUTPUT[적합도] {'chi2': 4.5, 'df': 5, 'p': 0.4799..., 'crit_0.05': 11.07..., 'reject_H0': False} [독립성] chi2=11.667, p=0.0029, V=0.241, reject=True 조정 잔차: [[ 3.09 -2.89 0. ] [-3.09 2.89 0. ]]
실무 팁 pandas.crosstab(df['성별'], df['음료'])로 원자료에서 바로 분할표를 만든 뒤 chi_square_table()에 넣으면 전처리부터 사후분석까지 한 흐름으로 처리됩니다. $2\times2$ 표는 correction=True(Yates 보정)가 기본 권장값입니다.
