Attention 주의력 분석

집중/분산 주의력 조건에서의 인지 과제 수행 점수 분석

📋 데이터셋 소개

attention은 인지심리학 주의력 실험 데이터로, 10명 피험자가 '집중(focused)' 및 '분산(divided)' 두 가지 주의력 조건에서 1·2·4글자 과제를 수행한 점수를 기록합니다.

📊 변수 설명

변수설명유형
Observation피험자 번호 (1~10)범주
attention주의력 유형 (focused / divided)이진 범주
Solutions과제 조건 (1/2/4 letters)순서형 범주
score수행 점수수치

🔬 분석 방법

① 반복측정 ANOVA
주의력 유형 × 과제 조건의 교호작용 효과 검정
② 시각화
조건별 평균 점수 프로파일과 오차 막대
③ 효과 크기
Cohen's d로 두 조건 간 차이의 실질적 크기 측정
④ 피험자별 분석
개인 간 변동성 및 조건 일관성 확인

📈 시각화 결과

주의력 유형 × 조건별 점수

점수 분포 & 피험자 상관

💡 결과 해석

📊 집중 > 분산: focused 조건이 전반적으로 높은 점수. 주의력 분산이 수행 저하를 야기.
📈 과제 난이도: 글자 수가 많을수록 점수 저하. 4 letters 조건에서 두 유형 간 차이가 더 벌어짐.
👤 개인 차이: 피험자마다 기저 수행 수준은 다르나, 대부분 focused > divided 패턴 일관.

💻 실행 코드

import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
import pingouin as pg  # 반복측정 ANOVA

attention = sns.load_dataset('attention')
print(attention.head())

# 반복측정 ANOVA (pingouin 사용)
# aov = pg.rm_anova(data=attention, dv='score',
#                   within=['attention', 'Solutions'],
#                   subject='Observation')
# print(aov)

# 기술 통계
print(attention.groupby(['attention','Solutions'])['score'].describe())

# 시각화
fig, ax = plt.subplots(figsize=(8, 5))
for att in ['focused', 'divided']:
    sub = attention[attention['attention']==att].groupby('Solutions')['score'].mean()
    ax.plot(sub.index, sub.values, marker='o', label=att)
ax.legend(); ax.set_title('주의력 유형 × 과제 조건별 점수')
plt.tight_layout(); plt.show()

📌 요약

🎯분석 목적: 주의력 유형(집중/분산) × 과제 난이도의 점수 차이 분석
📊핵심 발견: focused > divided, 과제 난이도 ↑ → 점수 ↓
