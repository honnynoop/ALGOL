💡 결과 해석

🌡️ 명확한 감소 추세: 9월 최솟값이 연간 약 0.039백만 km² 감소 (R²=0.50). 40년간 약 50% 감소.
📅 계절성: 3월 최대(~15백만 km²) → 9월 최소(~5백만 km²). 여름 해빙이 겨울보다 훨씬 빠르게 감소.
📊 가속화: 2000년대 이후 감소 속도가 이전 대비 빨라짐 — 지구온난화 가속의 반영.
🔮 미래 예측: 현재 추세 지속 시 2050년경 여름 북극 해빙 소멸 가능성 (과학계 경고).

💻 실행 코드

import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
import numpy as np

# 데이터 로드
df = sns.load_dataset('seaice')
df['Date'] = pd.to_datetime(df['Date'])
df['Year'] = df['Date'].dt.year
df['Month'] = df['Date'].dt.month

# 9월 최솟값 추세
sept = df[df['Month'] == 9]
slope, intercept, r, p, _ = stats.linregress(sept['Year'], sept['Extent'])
print(f"연간 해빙 감소: {slope:.4f} 백만 km²/년")
print(f"R² = {r**2:.3f}, p-value = {p:.2e}")

# 시각화
fig, axes = plt.subplots(2, 1, figsize=(12, 8))
# 전체 시계열
axes[0].plot(df['Date'], df['Extent'], alpha=0.5, label='월별 면적')
axes[0].plot(df[df['Month']==9]['Date'],
             df[df['Month']==9]['Extent'], 'r-', label='9월 최솟값')
axes[0].set_title('북극 해빙 면적 추이')
axes[0].legend()

# 9월 추세선
axes[1].scatter(sept['Year'], sept['Extent'])
axes[1].plot(sept['Year'], slope * sept['Year'] + intercept, 'r--')
axes[1].set_title(f'9월 최솟값 감소 추세 (R²={r**2:.3f})')
plt.tight_layout(); plt.show()
