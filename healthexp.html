💡 결과 해석

📈 양의 상관관계: 보건지출과 기대수명은 강한 로그 선형 관계 (R²≈0.75). 지출이 높을수록 기대수명 증가.
🇺🇸 미국의 역설: 최고 보건지출임에도 기대수명이 유럽 선진국보다 낮음 — 의료 접근성·비효율성 문제.
📊 시계열 추이: 1970년 이후 모든 국가에서 기대수명 상승. 저소득 국가의 개선 폭이 가장 큼.
⚠️ 불평등: 고소득국(평균 80세)과 저소득국(55세)의 기대수명 격차는 25년 이상.

💻 실행 코드

import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
import numpy as np

# 데이터 로드
df = sns.load_dataset('healthexp')
print(df.head())
print(df.dtypes)

# 최신 연도 필터링
recent = df[df['Year'] == df['Year'].max()]

# 회귀 분석
slope, intercept, r, p, _ = stats.linregress(
    np.log1p(recent['Spending']), recent['Life_Expectancy'])
print(f"R² = {r**2:.3f}, p = {p:.4f}")

# 산점도 + 회귀선
fig, ax = plt.subplots(figsize=(10, 6))
for country in recent['Country'].unique():
    sub = recent[recent['Country'] == country]
    ax.scatter(sub['Spending'], sub['Life_Expectancy'], s=80)
    ax.annotate(country, (sub['Spending'].values[0], sub['Life_Expectancy'].values[0]),
                fontsize=8, xytext=(5, 3), textcoords='offset points')

x_fit = np.linspace(recent['Spending'].min(), recent['Spending'].max(), 100)
ax.plot(x_fit, slope * np.log1p(x_fit) + intercept, 'r--', label=f'추세선 R²={r**2:.2f}')
ax.set_xscale('log')
ax.legend(); plt.tight_layout(); plt.show()
