이산

이산 확률분포 (Discrete Distributions)

확률변수가 가산 개의 값을 가지는 분포 — PMF로 표현

베르누이 분포
Bernoulli Distribution
B(1, p)
p 성공 확률 (0<p<1) q = 1−p 실패 확률 X ∈ {0, 1}
PMF
P(X=x) = px q1−x
x ∈ {0, 1}
누적분포함수 CDF
F(x) = 0 (x<0)
= q (0≤x<1)
= 1 (x≥1)
기댓값
p
분산
pq
왜도
(q−p)/√(pq)
첨도
1/pq − 6
관계: 이항분포 B(n,p)에서 n=1인 특수 경우. 모든 이항 시행의 최소 단위.
이항 분포
Binomial Distribution
B(n, p)
n 시행 횟수 (양의 정수) p 성공 확률 X = 성공 횟수 X ∈ {0,1,…,n}
PMF
P(X=k) = C(n,k) pk qn−k
적률생성함수 MGF
M(t) = (q + pet)n
기댓값
np
분산
npq
최빈값
⌊(n+1)p⌋
왜도
(q−p)/√(npq)
근사: n이 크고 p가 작으면 포아송 Po(np)로 근사. n이 크고 p≈0.5이면 정규분포 N(np, npq)로 근사 (중심극한정리).
음이항과 대칭 관계: 이항은 n 고정 → 성공 수 관찰. 음이항은 목표 성공 수 r 고정 → 시행 수 관찰.
초기하 분포
Hypergeometric Distribution
HG(N, K, n)
N 전체 모집단 크기 K 모집단 내 성공 원소 수 n 추출 수 (비복원) X = 추출 중 성공 수
PMF
P(X=k) = C(K,k) · C(N−K, n−k)C(N, n)
범위
max(0, n+K−N) ≤ k
≤ min(n, K)
기댓값
nK/N
분산
n·K(N−K)(N−n) / N²(N−1)
유한모집단 수정
(N−n)/(N−1)
이항 수렴
N→∞ 시 B(n,K/N)
이항분포와 차이: 비복원 추출이므로 시행이 독립이 아님. 유한모집단 수정계수 (N−n)/(N−1)만큼 분산이 작아짐.
음의 초기하와 대칭: 초기하는 n 고정 → 성공 수 관찰. 음의 초기하는 목표 성공 수 r 고정 → 시행 수 관찰.
기하 분포
Geometric Distribution
Geo(p)
p 성공 확률 X = 첫 성공까지의 시행 수 X ∈ {1, 2, 3, …}
PMF (시행 수 정의)
P(X=k) = qk−1 p
k = 1, 2, 3, …
PMF (실패 수 정의)
P(Y=k) = qk p
k = 0, 1, 2, …
기댓값
1/p
분산
q/p²
무기억성
P(X>m+n | X>m) = P(X>n)
음이항 관계
NB(1,p) = Geo(p)
무기억성 (Memoryless Property): 이산분포 중 기하분포만이 유일하게 무기억성을 가집니다. 연속형 대응은 지수분포.
정의 주의: X=시행 수이면 E[X]=1/p, X=실패 수이면 E[X]=q/p. 시험에서 정의 확인 필수.
포아송 분포
Poisson Distribution
Po(λ)
λ > 0 단위시간(공간)당 평균 발생률 X ∈ {0, 1, 2, …}
PMF
P(X=k) = λk e−λk!
MGF
M(t) = exp(λ(et−1))
기댓값
λ
분산
λ (= 기댓값)
왜도
1/√λ
가산성
Po(λ₁)+Po(λ₂) = Po(λ₁+λ₂)
포아송 과정 조건: ① 사건은 독립 ② 단위 시간당 평균 발생률 λ 일정 ③ 동시 발생 불가.
이항 근사 조건: n이 크고 p가 작을 때 B(n,p) ≈ Po(λ=np). 실무 기준: n≥20, p≤0.05.
정규 근사: λ ≥ 30이면 N(λ, λ)로 근사 가능.
다항 분포
Multinomial Distribution
Multi(n; p₁,…,pₖ)
n 총 시행 횟수 k 범주 수 pᵢ i번째 범주 확률, Σpᵢ=1 Xᵢ i번째 범주 빈도, ΣXᵢ=n
PMF
P(X₁=x₁,…,Xₖ=xₖ)
= n!x₁! ··· xₖ! p₁x₁···pₖxₖ
주변분포
각 Xᵢ ~ B(n, pᵢ)
E[Xᵢ] = npᵢ
Var[Xᵢ] = npᵢqᵢ
E[Xᵢ]
npᵢ
Var[Xᵢ]
npᵢ(1−pᵢ)
Cov[Xᵢ,Xⱼ]
−npᵢpⱼ
이항 관계
k=2 이면 이항분포
관계: k=2이면 이항분포와 동일. 카이제곱 검정의 이론적 기반.
연속

연속 확률분포 (Continuous Distributions)

확률변수가 실수 구간의 값을 가지는 분포 — PDF로 표현

연속 균일 분포
Continuous Uniform Distribution
U(a, b)
a 하한 b 상한 (a < b) X ∈ [a, b]
PDF
1b−a  (a ≤ x ≤ b)
0   (otherwise)
CDF
x−ab−a  (a ≤ x ≤ b)
기댓값
(a+b)/2
분산
(b−a)²/12
왜도
0
첨도
−6/5
활용: 난수 생성의 기반. 역변환 표집(inverse transform sampling)에서 시작점.
정규 분포 (가우스 분포)
Normal (Gaussian) Distribution
N(μ, σ²)
μ 평균 (위치) σ² > 0 분산 (척도) X ∈ (−∞, +∞)
PDF
f(x) = 1σ√(2π) exp−(x−μ)²2σ²
MGF
M(t) = exp(μt + σ²t²/2)
기댓값
μ
분산
σ²
왜도
0 (대칭)
첨도 (초과)
0
68-95-99.7 규칙: P(μ±σ)≈68.3%, P(μ±2σ)≈95.4%, P(μ±3σ)≈99.7%.
재생성: X₁~N(μ₁,σ₁²), X₂~N(μ₂,σ₂²) 독립이면 X₁+X₂~N(μ₁+μ₂, σ₁²+σ₂²).
표준화: Z = (X−μ)/σ ~ N(0,1).
표준정규 분포
Standard Normal Distribution
N(0, 1)
μ = 0 평균 σ² = 1 분산 Z ∈ (−∞, +∞)
PDF
φ(z) = 1√(2π) e−z²/2
CDF (표기)
Φ(z) = P(Z ≤ z)
Φ(−z) = 1 − Φ(z)
주요 z값
z₀.₀₅=1.645
양측 5%
z₀.₀₂₅=1.96
양측 1%
z₀.₀₀₅=2.576
관계
Z²~χ²(1)
활용: 가설검정의 z-검정, 신뢰구간 계산, 표준화 점수(z-score) 계산. 표에서 Φ(z) 조회 방법 숙지 필수.
지수 분포
Exponential Distribution
Exp(λ)
λ > 0 발생률(율 모수) X = 다음 사건까지 대기 시간 X ∈ [0, ∞)
PDF
f(x) = λ e−λx   (x ≥ 0)
CDF & 생존함수
F(x) = 1 − e−λx
S(x) = e−λx
기댓값
1/λ
분산
1/λ²
무기억성
P(X>s+t|X>s) = P(X>t)
감마 관계
Gamma(1, λ)
무기억성: 연속분포 중 유일하게 무기억성. 기하분포의 연속형 대응.
포아송과 관계: 포아송 과정에서 사건 간 대기시간 ~ Exp(λ).
주의: 척도 모수 θ=1/λ로 쓰는 경우도 있어 E[X]=θ로 표현되기도 함.
감마 분포
Gamma Distribution
Gamma(α, β)
α > 0 형상(shape) β > 0 척도(scale) 또는 율(rate)=1/β X ∈ (0, ∞)
PDF (척도 β 기준)
f(x) = xα−1e−x/ββα Γ(α)
감마 함수
Γ(n) = (n−1)!   (n∈ℤ⁺)
Γ(1/2) = √π
Γ(α+1) = α·Γ(α)
기댓값
αβ
분산
αβ²
왜도
2/√α
첨도(초과)
6/α
특수 경우: α=1이면 Exp(1/β). α=n/2, β=2이면 χ²(n) (카이제곱분포).
가산성: 독립인 Gamma(α₁,β) + Gamma(α₂,β) = Gamma(α₁+α₂, β).
포아송 관계: r번째 사건까지 대기시간 ~ Gamma(r, 1/λ).
베타 분포
Beta Distribution
Beta(α, β)
α > 0 형상 모수 1 β > 0 형상 모수 2 X ∈ (0, 1)
PDF
f(x) = xα−1(1−x)β−1B(α, β)
B(α,β) = Γ(α)Γ(β)/Γ(α+β)
특수 형태
α=β=1 → U(0,1)
α=β → 대칭 분포
α<1, β<1 → U자형
α>1, β>1 → 종모양
기댓값
α/(α+β)
분산
αβ / (α+β)²(α+β+1)
최빈값
(α−1)/(α+β−2)
활용
베이지안 사전분포
켤레 사전분포: 이항 가능도의 베이지안 사전분포로 활용. 사후분포도 베타분포.
균일분포 포함: α=β=1이면 U(0,1)과 동일.
로그정규 분포
Log-Normal Distribution
LN(μ, σ²)
μ log(X)의 평균 σ² log(X)의 분산 X ∈ (0, ∞)
PDF
f(x) = 1xσ√(2π)exp−(lnx−μ)²2σ²
정규분포와 관계
X~LN(μ,σ²)
⟺ ln(X)~N(μ,σ²)
기댓값
exp(μ+σ²/2)
분산
(e^σ²−1)e^(2μ+σ²)
중앙값
e^μ
왜도
양의 비대칭
활용: 주가, 소득분포, 물질 농도 등 항상 양수이며 오른쪽 꼬리가 긴 데이터. 곱의 중심극한정리로 유도.
와이블 분포
Weibull Distribution
W(k, λ)
k > 0 형상(shape) 모수 λ > 0 척도(scale) 모수 X ∈ [0, ∞)
PDF
f(x) = kλ(xλ)k−1 exp(−(x/λ)k)
고장률 h(x)
h(x) = kλ(xλ)k−1
k<1: 감소형, k=1: 일정, k>1: 증가형
기댓값
λ Γ(1+1/k)
분산
λ²[Γ(1+2/k)−(Γ(1+1/k))²]
k=1
지수분포 Exp(1/λ)
k=2
레일리 분포
신뢰성 분석: 제품 수명, 고장 시간 모델링에 핵심. 형상 k로 고장률 패턴(욕조 곡선) 표현.
k<1: 초기 고장기, k=1: 우발 고장기, k>1: 마모 고장기.
표본

표본 분포 (Sampling Distributions)

통계량의 분포 — 가설검정·신뢰구간의 핵심 도구

카이제곱 분포
Chi-Squared Distribution
χ²(ν)
ν 자유도 (양의 정수) X ∈ (0, ∞) Z²~χ²(1) (Z: 표준정규)
PDF
f(x) = xν/2−1 e−x/22ν/2Γ(ν/2)
정규분포와 관계
Zᵢ~N(0,1) 독립이면
Σ Zᵢ² ~ χ²(n)
(i=1,…,n)
기댓값
ν
분산
2ν
왜도
√(8/ν)
감마 관계
Gamma(ν/2, 2)
표본 분산: Xᵢ~N(μ,σ²) i.i.d. 일 때 (n−1)S²/σ² ~ χ²(n−1).
활용: 분산 추정·검정, 독립성 검정, 적합도 검정 (카이제곱 검정).
가산성: χ²(ν₁) + χ²(ν₂) = χ²(ν₁+ν₂) (독립일 때).
t 분포 (스튜던트 t)
Student's t-Distribution
t(ν)
ν 자유도 (양의 정수) T ∈ (−∞, +∞) Z~N(0,1), V~χ²(ν) 독립
PDF
f(t) = Γ((ν+1)/2)√(νπ)·Γ(ν/2)(1+t²/ν)−(ν+1)/2
구성
T = Z / √(V/ν)
또는
T = (X̄−μ) / (S/√n)
~ t(n−1)
기댓값
0 (ν>1)
분산
ν/(ν−2) (ν>2)
ν→∞ 극한
N(0,1)
꼬리 두께
ν 작을수록 두꺼움
핵심 활용: σ² 미지일 때 모평균 검정 (t-검정). 소표본(n<30)에서 필수.
ν≥30: 실무에서 정규분포로 근사. ν=1이면 코시분포 (기댓값, 분산 미존재).
대칭성: t(ν)는 0 대칭 → tα/2(ν) = −t₁₋α/2(ν).
F 분포 (피셔-스네데커)
F-Distribution
F(d₁, d₂)
d₁ 분자 자유도 d₂ 분모 자유도 F ∈ (0, ∞) U₁~χ²(d₁), U₂~χ²(d₂) 독립
구성
F = U₁/d₁U₂/d₂ = S₁²/σ₁²S₂²/σ₂²
다른 분포와 관계
1/F ~ F(d₂, d₁)
t²(ν) ~ F(1, ν)
F(1,∞) → χ²(1)
기댓값
d₂/(d₂−2) (d₂>2)
분산
2d₂²(d₁+d₂−2) / d₁(d₂−2)²(d₂−4)
역수 관계
F₁₋α(d₁,d₂) = 1/Fα(d₂,d₁)
활용
분산 비율 검정
ANOVA: 집단 간 분산 / 집단 내 분산 ~ F(k−1, n−k). 회귀분석 유의성 검정.
역수 관계: F 분포표는 단측 상위 임계값만 제공하므로 하위 임계값은 역수 관계 활용.
