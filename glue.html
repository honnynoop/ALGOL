💡 결과 해석

🥇 최고 성능: T5이 평균 87.2점으로 전체 1위. Transformer 계열 최신 모델의 우수성 확인.
📊 태스크 난이도: WNLI가 가장 어려운 태스크 (모든 모델 저조). SST-2는 상대적으로 쉬운 태스크.
🔍 모델 특성: T5·ELECTRA는 전반적 고성능. GPT는 생성 모델 특성상 이해 태스크에서 상대적 약세.
⚠️ 공통 약점: WNLI는 모든 모델이 낮은 점수 — 상식 추론의 어려움을 시사.

💻 실행 코드

import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

# GLUE 데이터 로드
glue = sns.load_dataset('glue')
print(glue.head())
print(glue.columns.tolist())

# 피벗 테이블 생성
pivot = glue.pivot(index='Model', columns='Task', values='Score')

# 히트맵 시각화
plt.figure(figsize=(12, 6))
sns.heatmap(pivot, annot=True, fmt='.1f', cmap='RdYlGn',
            vmin=0, vmax=100, linewidths=0.5)
plt.title('GLUE Benchmark Scores')
plt.tight_layout()
plt.show()

# 모델 평균 성능
model_avg = glue.groupby('Model')['Score'].mean().sort_values(ascending=False)
print("모델 순위:")
print(model_avg)

# 태스크 난이도
task_avg = glue.groupby('Task')['Score'].mean().sort_values()
print("\n태스크 난이도 (낮을수록 어려움):")
print(task_avg)
