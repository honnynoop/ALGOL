Brain Networks 뇌 연결성 분석

50개 뇌 영역 기능적 연결성 분석 · PCA 차원 축소 · K-Means 군집화 · fMRI 기반

📋 데이터셋 소개

brain_networks는 50개의 뇌 관심 영역(ROI) 간 기능적 연결성(functional connectivity)을 fMRI 신호의 시간적 상관계수로 정량화한 데이터입니다. 영역들은 5개의 주요 뇌 기능 네트워크(디폴트 모드, 전두엽, 두정엽, 측두엽, 후두엽)로 분류됩니다. 뇌 네트워크 분석 및 차원 축소 학습에 적합한 데이터입니다.

5대 뇌 네트워크 설명

디폴트 모드 (Default Mode)

안정 시 활성화. 자기 참조적 사고, 기억 회상, 미래 계획. 집중 시 비활성화.

전두엽 (Frontal)

실행 기능, 의사결정, 작업기억, 주의 조절. 인지 제어의 중심 네트워크.

두정엽 (Parietal)

공간 처리, 감각 통합, 주의력. 손-눈 협응 및 숫자 처리에 관여.

측두엽 (Temporal)

언어 이해(베르니케 영역), 얼굴 인식, 장기기억 형성(해마).

후두엽 (Occipital)

시각 정보 처리의 일차 영역. V1~V5 시각 피질 포함.

💡 결과 해석

🧱 블록 대각 구조: 연결 행렬에서 각 네트워크 내 영역들이 강하게 연결(높은 상관). 이것이 "기능적 연결성 네트워크"의 핵심 특성.
📊 PCA 분리: PC1+PC2가 31.7% 설명. 후두엽(시각)이 다른 네트워크와 명확히 분리. 전두엽-두정엽은 인지 기능 공유로 PCA 공간에서 가까움.
🔗 연결 강도 차이: 동일 네트워크 평균 상관 0.594 vs 다른 네트워크 0.105. 네트워크 내부 연결이 네트워크 간보다 0.49 더 강함.
🤖 K-Means 성공: 사전 정보 없이 연결 패턴만으로 5군집 발견 — 알려진 해부학적 네트워크와 대체로 일치.

import seaborn as sns
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# ① 데이터 로드
brain = sns.load_dataset('brain_networks', index_col=0, header=[0, 1, 2])
# seaborn brain_networks는 다중 인덱스 형식
# 이 예제에서는 직접 구성한 연결 데이터 사용

# ② 연결 행렬 구성 (직접 구성 버전)
# regions = sorted 50개 ROI
# conn_mat[i, j] = 두 영역 간 상관계수

# ③ PCA
scaler = StandardScaler()
conn_scaled = scaler.fit_transform(conn_mat)  # conn_mat: 50×50

pca = PCA(n_components=10)
pca_result = pca.fit_transform(conn_scaled)
print(f"PC1+PC2 설명분산: {(pca.explained_variance_ratio_[:2].sum()*100):.1f}%")

# ④ K-Means 군집화
km = KMeans(n_clusters=5, random_state=42)
labels = km.fit_predict(conn_scaled)

# ⑤ 시각화
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# 연결 행렬 히트맵
import matplotlib.pyplot as plt
axes[0].imshow(conn_mat, cmap='RdBu_r', vmin=-0.3, vmax=1.0)
axes[0].set_title('Brain Connectivity Matrix')

# PCA 산점도
colors = ['blue','green','orange','red','purple']
for k in range(5):
    mask = labels == k
    axes[1].scatter(pca_result[mask, 0], pca_result[mask, 1],
                    c=colors[k], label=f'Cluster {k+1}', s=60, alpha=0.8)
axes[1].legend()
axes[1].set_title('PCA Visualization (K-Means Clusters)')
plt.tight_layout(); plt.show()
