💡 결과 해석

📊 회귀 성능: Ridge R²=0.944. 과속·음주·비주의 변수들이 총 사고율을 잘 설명.

🗺️ 지역별 차이: 남부 주들이 상대적으로 높은 사고율 경향. 북동부(NY, MA)는 낮은 사고율 — 대중교통 이용률과 연관.
⚠️ 주의사항: 생태학적 오류(ecological fallacy) — 주 단위 집계 데이터로 개인 수준의 결론 도출 불가. 50개 관측치는 회귀 모델에 작은 표본 크기임을 고려해야 함.

💻 실행 코드

import seaborn as sns
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import r2_score, mean_squared_error
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# ① 데이터 로드
car = sns.load_dataset('car_crashes')
print(car.head())
print(car.describe())

# ② 상관 분석
corr = car.select_dtypes(include='number').corr()
print("총 사고율과의 상관계수:")
print(corr['total'].sort_values(ascending=False))

# ③ 회귀 분석
features = ['speeding','alcohol','not_distracted','no_previous',
            'ins_premium','ins_losses']
X = car[features]; y = car['total']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s = scaler.transform(X_test)

for name, model in [('Linear', LinearRegression()),
                     ('Ridge', Ridge(alpha=1.0)),
                     ('RF', RandomForestRegressor(n_estimators=100))]:
    model.fit(X_train_s, y_train)
    y_pred = model.predict(X_test_s)
    print(f"{name}: R²={r2_score(y_test,y_pred):.3f}, "
          f"RMSE={mean_squared_error(y_test,y_pred)**0.5:.3f}")

# ④ K-Means 클러스터링
scaler2 = StandardScaler()
X_scaled = scaler2.fit_transform(car[['total','ins_premium','speeding']])
km = KMeans(n_clusters=2, random_state=42)
car['cluster'] = km.fit_predict(X_scaled)
print(car.groupby('cluster')[['total','ins_premium']].mean())

# ⑤ 히트맵 시각화
plt.figure(figsize=(10, 8))
sns.heatmap(corr, annot=True, fmt='.2f', cmap='RdBu_r',
            vmin=-1, vmax=1, linewidths=0.5)
plt.title('Car Crashes 변수 간 상관관계')
plt.tight_layout(); plt.show()
