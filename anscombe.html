Anscombe's Quartet(앤스콤 사중주)는 1973년 통계학자 프랜시스 앤스콤(Francis Anscombe)이 만든 4개의 작은 데이터셋으로, 동일한 기술통계(평균·분산·회귀선·상관계수)를 가지지만 전혀 다른 분포를 가집니다. "항상 데이터를 시각화하라"는 교훈을 전달하는 데이터 시각화의 고전 사례입니다.

💡 결과 해석

📐 데이터셋 I — 선형 관계: 진정한 선형 관계. 회귀 가정 모두 충족. R²≈0.667로 적당한 설명력.
📈 데이터셋 II — 비선형 관계: 이차함수 패턴이지만 선형 회귀가 적용됨. 회귀는 유의하지만 모델이 부적합 — 다항 회귀 필요.
⚠️ 데이터셋 III — 이상치: 거의 완벽한 선형 관계 + 1개의 강력한 이상치. 이상치 1개가 회귀선 전체를 왜곡. → 이상치 제거 후 R²가 크게 개선.
📊 데이터셋 IV — 수직 배치: x값이 8 하나로 거의 고정 (나머지 1개만 19). 회귀 자체가 의미 없는 극단적 사례. → 데이터 수집 오류 가능성 점검 필요.
🎯 핵심 교훈: 평균·분산·상관계수·회귀식이 동일해도 데이터 분포는 완전히 다를 수 있다. 항상 데이터를 먼저 시각화하라 (Always plot your data first).

💻 실행 코드

import seaborn as sns
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# ① 데이터 로드
anscombe = sns.load_dataset('anscombe')
print(anscombe.head())
print(anscombe['dataset'].unique())  # ['I', 'II', 'III', 'IV']

# ② 기술통계 비교 — 4개 데이터셋이 거의 동일!
for ds in ['I', 'II', 'III', 'IV']:
    sub = anscombe[anscombe['dataset'] == ds]
    slope, intercept, r, p, se = stats.linregress(sub['x'], sub['y'])
    print(f"DS {ds}: x̄={sub['x'].mean():.3f}, ȳ={sub['y'].mean():.3f}, "
          f"slope={slope:.3f}, R²={r**2:.3f}")

# ③ 시각화 (seaborn FacetGrid)
g = sns.FacetGrid(anscombe, col='dataset', col_wrap=2,
                  height=4, aspect=1.2)
g.map_dataframe(sns.scatterplot, x='x', y='y', s=80)
g.map_dataframe(sns.regplot, x='x', y='y',
                scatter=False, ci=None, line_kws={'color':'red','linestyle':'--'})
g.set_titles(col_template="데이터셋 {col_name}")
plt.suptitle("Anscombe's Quartet — 같은 통계, 다른 분포", y=1.02)
plt.tight_layout(); plt.show()

# ④ 잔차 진단
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
for ax, ds in zip(axes.flatten(), ['I', 'II', 'III', 'IV']):
    sub = anscombe[anscombe['dataset'] == ds]
    s, i, r, p, se = stats.linregress(sub['x'], sub['y'])
    residuals = sub['y'].values - (s * sub['x'].values + i)
    ax.scatter(sub['x'], residuals, s=80, edgecolors='white')
    ax.axhline(0, color='gray', linestyle='--')
    ax.set_title(f'DS {ds} 잔차')
plt.tight_layout(); plt.show()
