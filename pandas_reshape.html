아래 모든 예제는 이 거래 데이터 df 하나를 기준으로 합니다. date는 datetime으로 변환해 두었습니다.

groupby 결과(Series)에 이름 붙이기

groupby([...])['price'].sum()은 DataFrame이 아니라 Series를 돌려줍니다. 값(value) 부분의 이름은 Series.name에 담기며, 기본값은 원래 열 이름('price')입니다.

af.rename / to_frame / reset_index(name=) / agg이름 지정
목적에 따라 4가지 방법. Series로 유지할지, 표(DataFrame)로 바꿀지가 갈림길입니다.
af = df.groupby(['year','month'])['price'].sum()   # Series (name='price')

# ① Series 이름만 변경
af.rename('total_price')          # 또는  af.name = 'total_price'

# ② DataFrame으로 + 열 이름 (MultiIndex 유지)
af.to_frame('total_price')

# ③ 인덱스 평탄화 + 값 열 이름 (Series 전용 옵션)
af.reset_index(name='total_price')

# ④ 처음부터 named aggregation (권장)
df.groupby(['year','month']).agg(total_price=('price','sum'))
③ reset_index(name='total_price') 
   year  month  total_price
0  2024      6       230115
1  2024     11       210704
2  2025      1       216567
핵심 · reset_index(name=...)의 name 인자는 Series에만 있습니다 (DataFrame의 reset_index엔 없음). 분석용 표가 필요하면 처음부터 ④ named aggregation으로 시작하는 게 가장 깔끔합니다.

Series ↔ DataFrame 변환

to_frame / reset_index / unstack구조 변환
인덱스를 유지할지, 일반 열로 풀지, 교차표로 펼칠지에 따라 선택합니다.
af.to_frame('total')          # 값을 열로, 인덱스 유지
af.reset_index(name='total')  # 인덱스(year,month)도 일반 열로 (평탄화)
pd.DataFrame(af)              # 생성자 직접 (to_frame과 동일)
af.unstack(fill_value=0)      # MultiIndex 한 레벨을 열로 (피벗 표)
af.unstack(fill_value=0) 
month      1       6       11

선택 기준 · 표 모양만 바꾸려면 to_frame, year/month를 분석 열로 쓰려면 reset_index, year×month 교차표가 필요하면 unstack. unstack은 빈 칸이 NaN이 되어 값이 float이 되니, 정수 유지하려면 fill_value=0을 줍니다.
03

stack / unstack — wide ↔ long

서로 정반대 동작입니다. unstack은 인덱스를 열로 올려(넓게), stack은 열을 인덱스로 내려(길게) 데이터 모양을 바꿉니다.

unstack: 행 인덱스(month)를 열로 올려 넓게 · stack: 열을 인덱스로 내려 길게
wide = af.unstack(fill_value=0)   # year × month 교차표

# stack: 열(month)을 인덱스로 내려 long 형태 Series로
wide.stack()

# 왕복: stack().unstack() == 원본
wide.stack().unstack(fill_value=0).equals(wide)   # True
wide.stack()

다중 레벨 컬럼 · 열이 여러 단계면 stack(level=0) 또는 stack(level='year')로 내릴 레벨을 고릅니다. 버전 주의: pandas 3.0은 stack 시 결측을 유지합니다(과거 2.x는 NaN 조합을 기본 제거, dropna로 제어). 구버전 코드와 동작이 다를 수 있습니다.
04

날짜 처리 · dt.to_period

.dt 접근자는 datetime 타입에서만 동작합니다. 먼저 pd.to_datetime으로 변환해야 합니다.

dt.to_period / to_timestamp / 속성날짜
to_period는 날짜를 기간(월·분기·연) 단위로 묶어, year/month 열을 따로 안 만들고도 기간별 집계를 가능하게 합니다.
df['date'].dt.to_period('M')   # 월:   2024-11
df['date'].dt.to_period('Q')   # 분기: 2024Q4
df['date'].dt.to_period('Y')   # 연:   2024

# to_period로 월별 groupby (year/month 분리 불필요!)
df.groupby(df['date'].dt.to_period('M'))['price'].sum()

# 역변환 / 파이썬 객체화
af_m = df['date'].dt.to_period('M')
af_m.dt.to_timestamp()          # Period → Timestamp (월초)
df['date'].dt.to_pydatetime()   # → 파이썬 datetime 객체

# 자주 쓰는 속성 (to 계열 아님)
df['date'].dt.year, df['date'].dt.month, df['date'].dt.day_name()

05

정수 → 문자열 변환

astype(str) · zfill · 포맷형변환
열 전체 변환, 자릿수 0 패딩, 천 단위 콤마, 그리고 결측 함정.
df['year'].astype(str)                       # 열 → 문자열
df['month'].astype(str).str.zfill(2)         # 1 → '01' (0 패딩)
df['month'].apply(lambda x: f'{x:02d}')      # 동일
df['price'].apply(lambda x: f'{x:,}')        # 100704 → '100,704'

# ⚠ 결측이 섞인 정수 열은 내부적으로 float → '1.0'으로 변환됨
s = pd.Series([1, np.nan, 3])
s.astype(str)                  # ['1.0', 'nan', '3.0']   ← 함정
s.astype('Int64').astype(str)  # ['1', '<NA>', '3']    ← 해결
결과 
zfill : month 1 → '01'
comma : 100704 → '100,704'
naive : [1, NaN, 3].astype(str) → ['1.0', nan, '3.0']  (주의)
Int64 : .astype('Int64').astype(str) → ['1', NaN, '3']
함정 · 정수 열에 NaN이 하나라도 있으면 dtype이 float이라 astype(str) 시 '5.0'처럼 됩니다. nullable 정수형 astype('Int64')를 거치거나 fillna(0).astype(int) 후 변환하세요.
06

문자열 결합

+ · str.cat · agg join결합
열+열, 구분자·결측 처리, 여러 열 한 번에, 그룹별 합치기까지.
# 열 + 열 (숫자는 astype(str) 먼저)
df['dept'] + '-' + df['name']                       # '영업-김철수'
df['year'].astype(str) + '-' + df['month'].astype(str).str.zfill(2)  # '2024-11'

# str.cat: 구분자/결측 옵션
df['dept'].str.cat(df['name'], sep='/', na_rep='-') # '영업/김철수'

# 여러 열 한 번에
df[['dept','name']].astype(str).agg('|'.join, axis=1)

# groupby에서 그룹별 문자열 합치기
df.groupby('dept')['name'].agg(', '.join)
df.groupby('dept')['name'].agg(lambda s: ','.join(s.unique()))  # 중복 제거
groupby('dept')['name'].agg(', '.join) 
dept
개발    이영희, 최지우, 정대현
영업         김철수, 박민수

주의 · +로 결합 시 한쪽이 NaN이면 결과도 NaN → str.cat(na_rep='')이나 fillna('')를 먼저. 그리고 pd.concat은 문자열이 아니라 DataFrame/Series를 행·열로 이어붙이는 함수라 용도가 전혀 다릅니다(혼동 주의).
