의료 분류에서 False Negative가 치명적
FN(거짓 음성): 악성인데 양성으로 예측 → 치료 지연 → 생명 위협

4 ROC 곡선과 AUC 원리 실제 확률 점수로 TPR·FPR 계산 — 근사 함수 아님
ROC 곡선 계산 원리 (정확한 방법)
① 모델이 각 샘플에 대해 양성(benign) 확률을 출력합니다.
② 이 확률을 오름차순 정렬합니다 (= 악성 점수 내림차순).
③ 정렬 순서대로 하나씩 "악성으로 예측"에 추가하면서 TPR과 FPR을 계산합니다.
④ (FPR, TPR) 점들을 이어 ROC 곡선을 그립니다.
⑤ AUC = 사다리꼴 공식(trapezoid rule)으로 곡선 아래 면적 계산.
확률 점수 분포 — 악성 vs 양성
Malignant benign_prob (낮을수록 악성)
Benign benign_prob (높을수록 양성)

두 분포의 겹치는 영역이 작을수록 AUC가 높음. 오른쪽(양성)과 왼쪽(악성)이 잘 분리됨

ROC 곡선 — 실제 확률 데이터에서 직접 계산

대각선(AUC=0.5)은 무작위 분류 기준선. 왼쪽 위 꼭짓점(0,1)에 가까울수록 우수

모델별 AUC 비교
AUC 해석 기준
0.90~1.00 : 우수 (Excellent) ← 우리 모델
0.80~0.90 : 좋음 (Good)
0.70~0.80 : 보통 (Fair)
0.50~0.60 : 실패 (Fail)
Precision-Recall 곡선 — 클래스 불균형 시 더 정보량 많음

PR 곡선은 불균형 데이터에서 ROC보다 더 엄격한 평가. AP(Average Precision)가 높을수록 우수

ROC · AUC 코드 (정확한 버전)Step 3
from sklearn.metrics import roc_curve, auc, roc_auc_score
from sklearn.metrics import precision_recall_curve, average_precision_score
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
import matplotlib.pyplot as plt

X, y = bc.data, bc.target
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3,
                          random_state=42, stratify=y)
ss = StandardScaler()
X_tr_s = ss.fit_transform(X_tr)
X_te_s  = ss.transform(X_te)

lr = LogisticRegression(max_iter=300)
lr.fit(X_tr_s, y_tr)

# predict_proba[:,1] = benign 확률
y_prob = lr.predict_proba(X_te_s)[:, 1]

# ── ROC 곡선 계산 ─────────────────────────────────────
# fpr: 1-Specificity (FP Rate)
# tpr: Sensitivity = Recall (TP Rate)
# thresholds: 각 지점의 decision boundary
fpr, tpr, thresholds = roc_curve(y_te, y_prob)
auc_score = auc(fpr, tpr)
print(f"AUC: {auc_score:.4f}")

# ── AUC 계산 원리: 사다리꼴 공식 ──────────────────────
# auc = sum((fpr[i]-fpr[i-1]) * (tpr[i]+tpr[i-1]) / 2)
manual_auc = sum(
    (fpr[i]-fpr[i-1]) * (tpr[i]+tpr[i-1]) / 2
    for i in range(1, len(fpr))
)
print(f"직접 계산 AUC: {manual_auc:.4f}")  # 동일!

# ── ROC 시각화 ────────────────────────────────────────
plt.figure(figsize=(7,6))
plt.plot(fpr, tpr, color='#185FA5', lw=2,
         label=f'LogReg (AUC={auc_score:.3f})')
plt.plot([0,1],[0,1],'k--',lw=1,label='Random (AUC=0.5)')
plt.fill_between(fpr, tpr, alpha=0.1, color='#185FA5')
plt.xlabel('FPR (1 - 특이도)')
plt.ylabel('TPR (민감도 = Recall)')
plt.title('ROC 곡선'); plt.legend()
plt.tight_layout(); plt.show()

# ── Precision-Recall 곡선 ─────────────────────────────
# pos_label=0: malignant를 양성 클래스로 설정
prec, rec, _ = precision_recall_curve(y_te, 1-y_prob, pos_label=0)
ap = average_precision_score(y_te, 1-y_prob, pos_label=0)
print(f"AP (Average Precision): {ap:.4f}")
5 임계값(Threshold) 조정 인터랙티브 임계값 변화 → Recall·Precision 트레이드오프 실시간 확인
임계값 방향 이해하기 — 핵심!
본 시뮬레이션에서 임계값 = benign 확률 기준입니다.
• 임계값 ↑ 높일수록: "양성 판정을 더 엄격하게" → 더 많은 샘플을 악성으로 분류 → 악성 Recall 증가, FP 증가
• 임계값 ↓ 낮출수록: "양성 판정을 더 관대하게" → 악성을 놓칠 수 있음 → 악성 Recall 감소, FP 감소
→ 의료 현장에서는 임계값을 0.6~0.7로 높여 악성 탐지율을 극대화합니다.
임계값: 0.50
임계값 변화에 따른 지표 트레이드오프
임계값 조정 코드Step 4
import numpy as np
from sklearn.metrics import (precision_score, recall_score,
                              f1_score, accuracy_score, roc_curve)

y_prob = lr.predict_proba(X_te_s)[:, 1]  # benign 확률

# ── 임계값별 지표 비교 ─────────────────────────────────
# predict_benign if prob >= thresh else predict_malignant
results = []
for thresh in np.arange(0.1, 0.92, 0.05):
    # 악성(0)을 더 잡으려면 thresh를 높여야 함!
    y_pred = (y_prob >= thresh).astype(int)   # 0=malignant, 1=benign
    results.append({
        'thresh':  round(thresh,2),
        'accuracy': accuracy_score(y_te, y_pred),
        'recall_mal':    recall_score(y_te, y_pred,    pos_label=0),
        'precision_mal': precision_score(y_te, y_pred, pos_label=0, zero_division=0),
        'f1_mal':        f1_score(y_te, y_pred,      pos_label=0, zero_division=0),
    })
result_df = pd.DataFrame(results)
print(result_df.round(3))

# ── Youden's J 최적 임계값 (ROC 기반 자동 선택) ───────
# TPR-FPR을 최대화하는 임계값
# pos_label=0: malignant를 positive로 설정
fpr, tpr, thresholds = roc_curve(y_te, 1-y_prob, pos_label=0)
youden_j = tpr - fpr
optimal_idx   = np.argmax(youden_j)
optimal_thresh_mal = thresholds[optimal_idx]  # malignant prob threshold
optimal_thresh_ben = 1 - optimal_thresh_mal   # benign prob threshold
print(f"Youden J 최적 (benign 기준): {optimal_thresh_ben:.3f}")

# 최적 임계값 적용
y_pred_opt = (y_prob >= optimal_thresh_ben).astype(int)
print("Recall(악성):", recall_score(y_te, y_pred_opt, pos_label=0).round(4))
print(classification_report(y_te, y_pred_opt, target_names=bc.target_names))

# Breast Cancer 완전 분석: EDA → 스케일링 → ROC → 임계값 → 평가
# ─────────────────────────────────────────────────────────────
import numpy as np, pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets    import load_breast_cancer
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.feature_selection import f_classif, SelectKBest
from sklearn.model_selection  import (train_test_split,
    cross_val_score, StratifiedKFold, GridSearchCV)
from sklearn.pipeline  import Pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.svm          import SVC
from sklearn.ensemble     import RandomForestClassifier
from sklearn.metrics      import (roc_curve, auc, roc_auc_score,
    precision_recall_curve, average_precision_score,
    classification_report, confusion_matrix, ConfusionMatrixDisplay,
    recall_score, precision_score, f1_score, accuracy_score)

# ── 0. 로드 ────────────────────────────────────────────────
bc = load_breast_cancer()
X, y = bc.data, bc.target     # 0=malignant, 1=benign

# ── 1. 분할 + 표준화 ─────────────────────────────────────
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)
ss = StandardScaler()
X_tr_s = ss.fit_transform(X_tr)
X_te_s  = ss.transform(X_te)

# ── 2. 특성 중요도 ────────────────────────────────────────
f_vals, _ = f_classif(X_tr_s, y_tr)
feat_imp = pd.Series(f_vals, index=bc.feature_names).sort_values(ascending=False)
print(feat_imp.head(10).round(0))

# ── 3. 모델 학습 + ROC ───────────────────────────────────
models = {'LR':LogisticRegression(max_iter=300),
          'SVM':SVC(kernel='rbf',probability=True),
          'RF':RandomForestClassifier(100,random_state=42)}

plt.figure(figsize=(8,6))
for name, m in models.items():
    m.fit(X_tr_s, y_tr)
    y_p = m.predict_proba(X_te_s)[:,1]
    fp, tp, _ = roc_curve(y_te, y_p)
    score = auc(fp, tp)
    plt.plot(fp, tp, lw=2, label=f'{name} AUC={score:.3f}')
plt.plot([0,1],[0,1],'k--',lw=1)
plt.xlabel('FPR'); plt.ylabel('TPR')
plt.title('ROC 곡선'); plt.legend(); plt.tight_layout(); plt.show()

# ── 4. Youden's J 최적 임계값 (benign prob 기준) ─────────
lr = models['LR']
y_prob = lr.predict_proba(X_te_s)[:,1]

fpr_r, tpr_r, thresh_r = roc_curve(y_te, 1-y_prob, pos_label=0)
opt_idx = np.argmax(tpr_r - fpr_r)
opt_thresh_ben = 1 - thresh_r[opt_idx]   # benign prob 기준으로 변환
print(f"Youden J 최적 임계값(benign기준): {opt_thresh_ben:.3f}")

y_pred_opt = (y_prob >= opt_thresh_ben).astype(int)
print(classification_report(y_te, y_pred_opt, target_names=bc.target_names))

# ── 5. Pipeline + GridSearchCV ────────────────────────────
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('select', SelectKBest(f_classif)),
    ('clf',    LogisticRegression(max_iter=300)),
])
gs = GridSearchCV(pipe,
    {'select__k':[10,15,20,30],'clf__C':[0.01,0.1,1,10]},
    cv=5, scoring='roc_auc', n_jobs=-1)
gs.fit(X_tr, y_tr)
print("최적:", gs.best_params_)
print("테스트 AUC:", roc_auc_score(y_te, gs.predict_proba(X_te)[:,1]).round(4))

시험 활용 포인트 (빅분기·ADP)
1. target 인코딩 주의: bc.target에서 0=malignant, 1=benign. roc_curve 기본값은 pos_label=1이므로 악성 기준 ROC에는 pos_label=0 설정
2. predict_proba 반드시 사용: ROC 계산엔 predict_proba(X)[:,1]. SVC는 probability=True 필수
3. 임계값 방향 주의: benign prob 기준 → 임계값 높일수록 Recall(악성) 증가 (직관과 반대!)
4. Youden's J: argmax(TPR − FPR)으로 최적 임계값 자동 선택
5. 평가지표 선택: 의료 = AUC + Recall(malignant), 일반 = Accuracy + F1
6. Pipeline: Scaler → SelectKBest → Classifier 묶기 → GridSearchCV에서 누수 방지
