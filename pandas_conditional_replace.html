Pandas · 조건부 대입

취소건 금액 부호 반전
.loc → where / mask / apply

cancel_TF == True인 행의 order_amt에 -1을 곱하는 동일 연산을 네 가지 방식으로 구현하고, 의미·결과·성능을 비교합니다.

00개요

원래 코드는 불리언 인덱싱(.loc)으로 취소건의 금액을 음수로 바꿉니다. 같은 결과를 where, mask, apply로도 표현할 수 있는데, 핵심은 "조건이 True인 곳을 바꾸느냐, 유지하느냐"의 방향입니다. 이 문서의 모든 수치 예시와 성능 결과는 Python으로 직접 실행해 검증했습니다.

01샘플 데이터 & 목표

import pandas as pd

df = pd.DataFrame({
    'order_id' : [1001, 1002, 1003, 1004, 1005],
    'cancel_TF': [False, True, False, True, True],
    'order_amt': [12000, 8500, 30000, 5000, 17000],
})

cancel_TF가 True인 행(1002·1004·1005)의 order_amt만 음수로 변환하는 것이 목표입니다.

order_idcancel_TF변환 전변환 후
1001False1200012000
1002True8500-8500
1003False3000030000
1004True5000-5000
1005True17000-17000

02방법 1 — .loc (원본)

df.loc[df['cancel_TF'] == True, 'order_amt'] = \
    df.loc[df['cancel_TF'] == True, 'order_amt'] * -1

조건에 맞는 행·열을 직접 선택해 해당 위치만 in-place로 대입합니다. 가장 직관적이고 빠른 표준 패턴입니다.

03방법 2 — where

df['order_amt'] = df['order_amt'].where(
    df['cancel_TF'] != True,      # 조건 True → 원본 유지
    df['order_amt'] * -1          # 조건 False → other 로 대체
)
주의 — 방향이 반대입니다. Series.where(cond, other)는 cond가 True인 곳을 "유지"하고 False인 곳을 other로 바꿉니다. 따라서 "취소건만 변환"하려면 조건을 뒤집어 cancel_TF != True(취소 아님 = 유지)로 줘야 합니다.
where ↔ mask : 정확히 반대 방향

04방법 3 — mask (권장)

df['order_amt'] = df['order_amt'].mask(
    df['cancel_TF'] == True,      # 조건 True → other 로 대체
    df['order_amt'] * -1
)
mask는 의미가 더 자연스럽습니다. "조건 True인 곳을 바꾼다"는 원래 의도와 방향이 일치하므로 조건을 뒤집을 필요가 없습니다. where를 요청하셨다면 위 방식을, 가독성을 우선한다면 mask를 쓰는 걸 권합니다.

05방법 4 — apply

df['order_amt'] = df.apply(
    lambda x: x['order_amt'] * -1 if x['cancel_TF'] == True
              else x['order_amt'],
    axis=1
)
가능하지만 비권장. apply(axis=1)은 행마다 Python 함수를 호출하는 반복 연산이라, 벡터화 방식보다 수백 배 느립니다(아래 벤치마크 참고). 결과는 동일하지만 대용량 데이터에서는 피하세요.

06비교 정리

방식조건 의미벡터화in-place비고
.locTrue 위치에 대입OO표준 패턴, 빠름
whereTrue 유지 / False 대체OX (재대입)조건 반전 필요
maskTrue 대체 / False 유지OX (재대입)의미 직관적
apply행 단위 분기XX (재대입)느림, 비권장

네 방식 모두 결과가 완전히 동일함을 Series.equals()로 확인했습니다.

07성능 벤치마크

100만 행 무작위 데이터(취소 비율 ≈30%) 기준 평균 실행 시간입니다. 막대가 짧을수록 빠릅니다.

mask 13.09 ms
.loc 15.79 ms
where 22.24 ms
apply 6515 ms
apply는 약 500배 느립니다. 벡터화 3종은 13~22ms인데 apply(axis=1)은 6,515ms로, 한 화면에 비례 표시하면 나머지 막대가 보이지 않을 정도입니다.

08선택 가이드

실무·시험 코드에서는 벡터화 3종 중 하나를 쓰세요. in-place 수정이 자연스러우면 .loc, 함수형 표현·체이닝을 선호하면 mask(조건 그대로)를, 과제에서 where를 명시했다면 조건을 반전해 사용하면 됩니다. apply(axis=1)은 행마다 복잡한 다중 컬럼 로직이 꼭 필요할 때만 제한적으로 씁니다. 

# 최종 권장 (가독성)
df['order_amt'] = df['order_amt'].mask(df['cancel_TF'], df['order_amt'] * -1)

# 요청대로 where 사용
df['order_amt'] = df['order_amt'].where(~df['cancel_TF'], df['order_amt'] * -1)
팁. cancel_TF가 이미 불리언 Series라면 == True 없이 df['cancel_TF'], ~df['cancel_TF']로 더 간결하게 쓸 수 있습니다.
