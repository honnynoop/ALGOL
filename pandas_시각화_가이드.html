groupby 핵심 — agg / transform / filter
agg — 집계 (행 수 감소)
1유형ADP
# Named aggregation ⭐ df.groupby('dept').agg( avg_sal=('salary', 'mean'), max_age=('age', 'max'), cnt=('name', 'count') ) # 여러 통계 한번에 df.groupby('dept')['salary'].agg( ['mean', 'std', 'min', 'max'] )

결과: 그룹 수만큼 행이 줄어들어 요약 테이블이 됨

transform — 원본 크기 유지 ⭐
1유형2유형
# 그룹 평균을 원본에 붙이기 df['dept_avg'] = df.groupby('dept')['salary' ].transform('mean') # 그룹 내 편차 df['salary_diff'] = ( df['salary'] - df.groupby('dept')['salary'] .transform('mean') )

핵심: 원본 DataFrame과 같은 행 수를 반환. merge 없이 그룹 정보를 붙일 수 있음

filter — 그룹 단위 필터링
ADP
# 직원 수 10명 이상 부서만 df.groupby('dept').filter( lambda x: len(x) >= 10 ) # 평균 급여 5000 이상 부서만 df.groupby('dept').filter( lambda x: x['salary'].mean() >= 5000 )

특징: 그룹 전체를 조건에 맞는 경우만 반환. 행 필터와 달리 그룹 단위로 유지/제거

빅분기 3유형 — 통계 검정 흐름
가설 검정 5단계 프로세스
1
가설 설정
H₀ (귀무가설) vs H₁ (대립가설) 정의
2
정규성 검정
stats.shapiro(data) — p < 0.05이면 비정규분포
3
등분산 검정 (필요 시)
stats.levene(g1, g2) — p < 0.05이면 이분산
4
검정 실시
t검정 / F검정 / χ² 검정 수행
5
결론 도출
p < 0.05 → H₀ 기각 / p ≥ 0.05 → H₀ 채택
상황별 검정 선택 가이드
상황검정함수
1개 집단, 모평균 비교 단일표본 t ttest_1samp(x, μ)
2개 독립 집단 평균 비교 독립표본 t ttest_ind(a, b)
전/후 비교 (같은 대상) 대응표본 t ttest_rel(a, b)
3개 이상 집단 평균 일원분산분석 f_oneway(*grps)
두 범주형 변수 독립성 카이제곱 chi2_contingency
두 수치형 변수 관계 상관분석 pearsonr(x, y)
⭐ 빅분기 3유형 완전 코드 템플릿
3유형 필수
from scipy import stats ## ① 정규성 확인 stat, p_norm = stats.shapiro(df['score'].dropna()) print(f"Shapiro p={p_norm:.4f}", "정규O" if p_norm>=0.05 else "정규X") ## ② 독립표본 t검정 예시 g1 = df[df['group']=='A']['score'].dropna() g2 = df[df['group']=='B']['score'].dropna() stat, p = stats.ttest_ind(g1, g2, equal_var=True) print(f"검정통계량: {round(stat, 4)}") print(f"p-value: {round(p, 4)}") print("귀무가설 기각" if p < 0.05 else "귀무가설 채택") ## ③ 일원분산분석 + 사후검정 groups = [df[df['dept']==d]['salary'] for d in df['dept'].unique()] stat, p = stats.f_oneway(*groups) if p < 0.05: from statsmodels.stats.multicomp import pairwise_tukeyhsd tukey = pairwise_tukeyhsd(df['salary'], df['dept'])
