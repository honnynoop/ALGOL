2 스케일링이 왜 필수인가? 특성 범위 차이 최대 2,500배 — 전처리 없이는 PCA·KNN·SVM 왜곡
스케일링 핵심 원리
proline은 278~1680 범위, nonflavanoid_phenols는 0.13~0.66 범위입니다. StandardScaler 없이 PCA를 적용하면 proline 하나가 PC1을 독점합니다. KNN·SVM도 거리 기반이므로 큰 단위 특성이 소단위 특성을 완전히 묻어버립니다.
특성별 값 범위 비교 (스케일링 전 vs 후)

StandardScaler 적용 후 모든 특성이 평균=0, 표준편차=1로 통일됨

StandardScaler — Z-score 표준화
각 특성을 (값 − 평균) / 표준편차 로 변환.
결과: 평균=0, 표준편차=1.
이상값에 민감하지만 대부분의 ML 알고리즘에 적합.
MinMaxScaler — 최솟값-최댓값 정규화
각 특성을 [0, 1] 범위로 압축.
(값 − min) / (max − min)
이상값 존재 시 왜곡 가능 — 와인 데이터는 StandardScaler 권장.
RobustScaler — 중앙값 기반
중앙값(median)과 IQR 사용.
(값 − median) / IQR
이상값이 많을 때 유리 — 와인 데이터는 덜 필요함.
스케일링 전·후 정확도 비교 (SVM)

StandardScaler 적용 시 SVM 정확도 65% → 99%로 급등

from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler

X, y = wine.data, wine.target

X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

# ── 스케일링 전 SVM ──────────────────────────────────
svm_raw = SVC(kernel='rbf')
svm_raw.fit(X_tr, y_tr)
print("스케일링 전:", svm_raw.score(X_te, y_te))  # ~0.648

# ── StandardScaler ────────────────────────────────────
ss = StandardScaler()
X_tr_ss = ss.fit_transform(X_tr)   # train에만 fit!
X_te_ss  = ss.transform(X_te)       # test는 transform만

svm_ss = SVC(kernel='rbf')
svm_ss.fit(X_tr_ss, y_tr)
print("StandardScaler 후:", svm_ss.score(X_te_ss, y_te))  # ~0.981

# ── MinMaxScaler ─────────────────────────────────────
mm = MinMaxScaler()
X_tr_mm = mm.fit_transform(X_tr)
X_te_mm  = mm.transform(X_te)

svm_mm = SVC(kernel='rbf')
svm_mm.fit(X_tr_mm, y_tr)
print("MinMaxScaler 후:",  svm_mm.score(X_te_mm, y_te))   # ~0.944

# ── 역변환: 원래 값 복원 ──────────────────────────────
X_original = ss.inverse_transform(X_tr_ss)

PCA 분석 코드 Step 4 
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

X, y = wine.data, wine.target

# 1. 표준화 (반드시 먼저!)
scaler = StandardScaler()
X_s = scaler.fit_transform(X)

# 2. 전체 주성분으로 분산 비율 확인
pca_full = PCA(n_components=13)
pca_full.fit(X_s)
evr = pca_full.explained_variance_ratio_
print("설명 분산 비율:", np.round(evr, 4))
print("누적 분산:",     np.round(np.cumsum(evr), 4))
# PC1  PC2  PC3  PC4 ... PC7 에서 누적 90% 돌파

# 3. 최적 n_components 선택: 90% 이상
n_comp = np.argmax(np.cumsum(evr) >= 0.90) + 1
print(f"90% 분산 보존에 필요한 PC 수: {n_comp}")  # 7

# 4. PCA 2D 시각화
pca2 = PCA(n_components=2)
X_2d = pca2.fit_transform(X_s)

colors = ['#D85A30', '#7F77DD', '#1D9E75']
fig, ax = plt.subplots(figsize=(8,6))
for i, name in enumerate(wine.target_names):
    m = y == i
    ax.scatter(X_2d[m,0], X_2d[m,1], c=colors[i], label=name,
               alpha=0.8, s=55, edgecolors='white', linewidths=0.5)
ax.set_xlabel(f"PC1 ({evr[0]*100:.1f}%)")
ax.set_ylabel(f"PC2 ({evr[1]*100:.1f}%)")
ax.legend(); ax.set_title('Wine PCA 2D (표준화 후)')
plt.tight_layout(); plt.show()

# 5. 로딩 행렬
loading = pd.DataFrame(pca2.components_.T,
    index=wine.feature_names, columns=['PC1','PC2'])
print(loading.sort_values('PC1', ascending=False).round(3))

# ─────────────────────────────────────────────────────────────
# Wine 완전 분석: EDA → 스케일링 → PCA → 다중분류 → 평가
# ─────────────────────────────────────────────────────────────
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.model_selection import (
    train_test_split, cross_val_score, StratifiedKFold, GridSearchCV)
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.neighbors import KNeighborsClassifier
from sklearn.feature_selection import f_classif, SelectKBest
from sklearn.metrics import (
    classification_report, confusion_matrix, ConfusionMatrixDisplay)

# ── 0. 데이터 로드 ─────────────────────────────────────────
wine = load_wine()
X, y = wine.data, wine.target
df = pd.DataFrame(X, columns=wine.feature_names)
df['class'] = pd.Categorical.from_codes(y, wine.target_names)
print(df.shape)  # (178, 14)
print(df['class'].value_counts())

# ── 1. 스케일 차이 확인 ────────────────────────────────────
print("범위(max-min):")
print((df.drop('class',axis=1).max() - df.drop('class',axis=1).min()).sort_values(ascending=False).round(1))

# ── 2. 분할 + 표준화 ───────────────────────────────────────
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)

ss = StandardScaler()
X_tr_s = ss.fit_transform(X_tr)
X_te_s  = ss.transform(X_te)

# ── 3. PCA ────────────────────────────────────────────────
pca = PCA(n_components=13)
pca.fit(X_tr_s)
evr = pca.explained_variance_ratio_
n90 = np.argmax(np.cumsum(evr) >= 0.90) + 1
print(f"90% 분산 보존 PC 수: {n90}")

pca2 = PCA(n_components=2)
X_2d = pca2.fit_transform(X_tr_s)
colors = ['#D85A30','#7F77DD','#1D9E75']
plt.figure(figsize=(8,6))
for i, name in enumerate(wine.target_names):
    m = y_tr == i
    plt.scatter(X_2d[m,0],X_2d[m,1],c=colors[i],label=name,alpha=0.8,s=55,edgecolors='white')
plt.xlabel(f"PC1 ({evr[0]*100:.1f}%)")
plt.ylabel(f"PC2 ({evr[1]*100:.1f}%)")
plt.legend(); plt.title('Wine PCA 2D'); plt.tight_layout(); plt.show()

# ── 4. 모델 비교 ───────────────────────────────────────────
models = {
    'LogReg': LogisticRegression(max_iter=500),
    'SVM':    SVC(kernel='rbf'),
    'KNN':    KNeighborsClassifier(5),
    'DTree':  DecisionTreeClassifier(random_state=42),
    'RF':     RandomForestClassifier(100,random_state=42),
    'GBM':    GradientBoostingClassifier(random_state=42),
}
cv = StratifiedKFold(5,shuffle=True,random_state=42)
for name, m in models.items():
    sc = cross_val_score(m, X_tr_s, y_tr, cv=cv)
    print(f"{name:8}: {sc.mean():.4f} ± {sc.std():.4f}")

# ── 5. Pipeline: Scaler → PCA → SVM ───────────────────────
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('pca',    PCA(n_components=7)),
    ('clf',    SVC(kernel='rbf',C=10))
])
param_grid = {
    'pca__n_components':[3,5,7,9,13],
    'clf__C':[0.1,1,10,100]
}
gs = GridSearchCV(pipe, param_grid, cv=5, scoring='accuracy', n_jobs=-1)
gs.fit(X_tr, y_tr)
print("최적:", gs.best_params_)
print("CV 최고:", gs.best_score_.round(4))
print("테스트:", gs.score(X_te, y_te).round(4))

# ── 6. 혼동 행렬 + 분류 보고서 ────────────────────────────
best_model = SVC(kernel='rbf',C=1.0)
best_model.fit(X_tr_s, y_tr)
y_pred = best_model.predict(X_te_s)
print(classification_report(y_te,y_pred,target_names=wine.target_names))
disp = ConfusionMatrixDisplay(confusion_matrix(y_te,y_pred),
                               display_labels=wine.target_names)
disp.plot(cmap='OrRd')
plt.title('Confusion Matrix — Wine SVM')
plt.tight_layout(); plt.show()

시험 활용 포인트 (빅분기·ADP)

4. 특성 중요도: f_classif(X, y)로 ANOVA F값 계산 → SelectKBest로 상위 k개 선택
5. GridSearchCV: pca__n_components + clf__C 동시 탐색으로 최적 파이프라인 구성
