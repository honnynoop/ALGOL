분산분석이란?

Why ANOVA — 왜 t검정을 여러 번 쓰면 안 되는가
⚠️ 3집단 비교를 t검정으로 3번 하면? 각각 α=0.05로 검정 시 → 실제 1종 오류율 = 1−(0.95)³ = 0.143 (14.3%)
집단이 늘수록 누적 오류 폭증 → 분산분석(ANOVA)으로 한 번에 검정!
H₀
귀무가설
모든 집단의 모평균이 같다
μ₁ = μ₂ = μ₃ = … = μₖ
H₁
대립가설
적어도 하나의 집단 평균이 다르다
(모두 다르다는 뜻이 아님!)
F
검정통계량
집단 간 분산 ÷ 집단 내 분산
F = MSB / MSW
k

일원분산분석: k≥3
이원분산분석: 요인 2개
α

보통 0.05 (5%)
p < α → H₀ 기각

분산 분해 원리

SST = SSB + SSW (총변동 = 집단 간 + 집단 내)
분산 분해 개념도 — 각 관측값의 편차 구조
핵심 공식 — 분산 분해
SST = SSB + SSW
총변동 = 집단 간 변동 + 집단 내 변동

MSB = SSB / (k−1)   ← 집단 간 평균제곱 (Between Mean Square)
MSW = SSW / (N−k)   ← 집단 내 평균제곱 (Within Mean Square)

F = MSB / MSW   ~ F(k−1, N−k) 분포

단계별 계산 과정

SSB · SSW · SST · df · MS · F 순서로
1
SSB (집단 간 변동) 계산 — 각 집단 평균과 전체 평균의 차이
SSB = Σ n_j × (x̄_j − x̄)² 집단 A: n₁ × (x̄₁ − x̄)² = 5 × (20.0 − 25.333)² = 5 × (−5.333)² = 5 × 28.444 = 142.222 집단 B: n₂ × (x̄₂ − x̄)² = 5 × (26.0 − 25.333)² = 5 × ( 0.667)² = 5 × 0.444 = 2.222 집단 C: n₃ × (x̄₃ − x̄)² = 5 × (30.0 − 25.333)² = 5 × ( 4.667)² = 5 × 21.778 = 108.889 ───────────────────────────────────────────────────────── SSB = 142.222 + 2.222 + 108.889 = 253.333
2
SSW (집단 내 변동) 계산 — 각 관측값과 집단 평균의 차이
SSW = ΣΣ (x_ij − x̄_j)² 집단 A: (20−20)²+(22−20)²+(19−20)²+(21−20)²+(18−20)² = 0+4+1+1+4 = 10 집단 B: (25−26)²+(27−26)²+(26−26)²+(28−26)²+(24−26)² = 1+1+0+4+4 = 10 집단 C: (30−30)²+(28−30)²+(31−30)²+(29−30)²+(32−30)² = 0+4+1+1+4 = 10 ───────────────────────────────────────────────────────── SSW = 10 + 10 + 10 = 30.000
3
SST (총변동) 계산 — 검증
SST = SSB + SSW SST = 253.333 + 30.000 = 283.333 ※ 직접 계산: SST = Σ(x_ij − x̄)² 로도 구할 수 있음 → 결과 동일 (검증)
4
자유도 (Degrees of Freedom) 계산
df 공식 df_B (집단 간) = k − 1 = 3 − 1 = 2 df_W (집단 내) = N − k = 15 − 3 = 12 df_T (전체) = N − 1 = 15 − 1 = 14 ───────────────────────────────────── 검증: df_B + df_W = 2 + 12 = 14 = df_T ✓
5
MS (평균제곱) 및 F통계량 계산
MS = SS / df     F = MSB / MSW MSB = SSB / df_B = 253.333 / 2 = 126.667 MSW = SSW / df_W = 30.000 / 12 = 2.500 ───────────────────────────────────── F = MSB / MSW = 126.667 / 2.500 = 50.667 F 임계값: F(df_B=2, df_W=12, α=0.05) = 3.885 F = 50.667 >> 3.885 → H₀ 기각!

사후검정 — Tukey HSD

어느 집단 간에 차이가 있는가? — Honestly Significant Difference
💡 왜 사후검정이 필요한가? ANOVA는 "적어도 하나가 다르다"만 알려줌. 어느 쌍이 다른지는 사후검정으로 확인.
Tukey HSD는 등분산·등표본일 때 가장 많이 사용되는 방법.
1
HSD (Honestly Significant Difference) 계산
HSD = q(α, k, df_W) × √(MSW / n) Studentized Range 통계량: q(0.05, k=3, df_W=12) = 3.773 ← 분포표에서 찾기 MSW = 2.500, n = 5 (각 집단 표본수) SE = √(MSW / n) = √(2.500 / 5) = √0.500 = 0.7071 HSD = 3.773 × 0.7071 = 2.667 cm ↑ 두 집단 평균 차이가 2.667 이상이면 유의미한 차이
2
쌍별 비교 (Pairwise Comparison)
비교 쌍평균 차이 |x̄ᵢ − x̄ⱼ|HSD = 2.667비교판정
A vs B |20.0 − 26.0| = 6.000 2.667 6.000 > 2.667 유의미한 차이 ✓
A vs C |20.0 − 30.0| = 10.000 2.667 10.000 > 2.667 유의미한 차이 ✓
B vs C |26.0 − 30.0| = 4.000 2.667 4.000 > 2.667 유의미한 차이 ✓

가정 검증 코드

ANOVA 실행 전 필수 확인
정규성 · 등분산성 검정
from scipy.stats import shapiro, levene, kruskal, f_oneway import numpy as np A = [20, 22, 19, 21, 18] B = [25, 27, 26, 28, 24] C = [30, 28, 31, 29, 32] # ① 정규성 검정 (Shapiro-Wilk) — 집단별 for name, grp in zip(['A','B','C'], [A,B,C]): stat, p = shapiro(grp) print(f"집단 {name}: W={stat:.4f}, p={p:.4f} → {'정규분포 ✓' if p>0.05 else '비정규 ✗'}") # ② 등분산성 검정 (Levene) stat, p = levene(A, B, C) print(f"\nLevene: F={stat:.4f}, p={p:.4f} → {'등분산 ✓' if p>0.05 else '이분산 ✗'}") # ③ 일원분산분석 실행 F_stat, p_val = f_oneway(A, B, C) print(f"\n일원ANOVA: F={F_stat:.4f}, p={p_val:.6f}") print(f"결론: {'H₀ 기각 — 집단 간 유의미한 차이 있음' if p_val<0.05 else 'H₀ 채택'}") # ④ 가정 위반 시: Kruskal-Wallis (비모수) H, p_kw = kruskal(A, B, C) print(f"\nKruskal-Wallis: H={H:.4f}, p={p_kw:.6f}")

Python 전체 코드

가정 검증 → ANOVA → 사후검정 → 효과 크기 완전 파이프라인
일원분산분석 완전 파이프라인
import pandas as pd import numpy as np from scipy.stats import shapiro, levene, f_oneway, kruskal from statsmodels.stats.multicomp import pairwise_tukeyhsd import statsmodels.api as sm from statsmodels.formula.api import ols # ─── 데이터 ────────────────────────────────────────────────── A = [20, 22, 19, 21, 18] B = [25, 27, 26, 28, 24] C = [30, 28, 31, 29, 32] df = pd.DataFrame({ 'growth': A + B + C, 'group' : ['A']*5 + ['B']*5 + ['C']*5 }) # ─── ① 기술 통계 ───────────────────────────────────────────── print(df.groupby('group')['growth'].agg(['mean','std','count'])) # ─── ② 정규성 (Shapiro-Wilk) ───────────────────────────────── print("=== 정규성 검정 ===") for g in ['A','B','C']: stat, p = shapiro(df[df.group==g]['growth']) print(f" 집단 {g}: W={stat:.4f}, p={p:.4f}") # ─── ③ 등분산성 (Levene) ───────────────────────────────────── stat, p = levene(A, B, C) print(f"\nLevene: F={stat:.4f}, p={p:.4f}") equal_var = p > 0.05 # ─── ④ 일원 ANOVA ──────────────────────────────────────────── F, p_anova = f_oneway(A, B, C) print(f"\nANOVA: F={F:.4f}, p={p_anova:.6f}") # statsmodels로 ANOVA 표 출력 model = ols('growth ~ C(group)', data=df).fit() anova_table = sm.stats.anova_lm(model, typ=2) print(anova_table) # ─── ⑤ 사후검정 (Tukey HSD) ───────────────────────────────── tukey = pairwise_tukeyhsd( endog = df['growth'], groups= df['group'], alpha = 0.05 ) print(tukey.summary()) # ─── ⑥ 효과 크기 (η²) ────────────────────────────────────── SS_B = anova_table['sum_sq']['C(group)'] SS_T = anova_table['sum_sq'].sum() eta2 = SS_B / SS_T print(f"\nη² (에타제곱) = {eta2:.4f}") # ─── ⑦ 이원분산분석 ───────────────────────────────────────── # df에 두 번째 요인 추가 시 model2 = ols('y ~ C(A) + C(B) + C(A):C(B)', data=df2).fit() anova2 = sm.stats.anova_lm(model2, typ=2) print(anova2) # ─── ⑧ Welch ANOVA (등분산 불만족 시) ────────────────────── import pingouin as pg welch = pg.welch_anova(data=df, dv='growth', between='group') print(welch) # ─── ⑨ Kruskal-Wallis (비모수, 정규성 불만족 시) ─────────── H, p_kw = kruskal(A, B, C) print(f"\nKruskal-Wallis: H={H:.4f}, p={p_kw:.6f}")
