분산분석 & 카이제곱의 원리

두 검정을 "관측된 차이 ÷ 우연히 기대되는 차이"라는 하나의 직관으로 묶어, 예제 수치와 실행 소스로 정리한 참고서

두 방법의 공통 원리

분산분석(ANOVA)과 카이제곱($\chi^2$) 검정은 다루는 자료가 다르지만, 밑바탕의 논리는 같습니다. 둘 다 다음 한 문장으로 요약됩니다.

핵심 직관 "내가 실제로 관측한 차이/변동이, 아무 효과가 없을 때(귀무가설) 우연히 생길 만한 차이/변동보다 충분히 큰가?" — 이 비교를 하나의 검정통계량으로 만들고, 그 값이 기준 분포의 꼬리(기각역)에 들어가면 "우연이 아니다"라고 결론 내립니다.

분산분석 — 변동(분산)으로 비교

연속형 측정값의 총변동을 "집단 때문에 생긴 변동"과 "집단 내부의 우연한 변동"으로 쪼갠다.

$$ F = \frac{\text{집단 간 변동}}{\text{집단 내 변동}} $$

카이제곱 — 도수로 비교

범주별 관측 빈도 O가 "효과가 없을 때의 기대 빈도 E"에서 얼마나 벗어났는지를 모은다.

$$ \chi^2 = \sum\frac{(O-E)^2}{E} $$

PART I 분산분석의 원리

원리 — 총변동을 두 조각으로 쪼갠다

관측값이 서로 다른 데는 두 가지 이유가 섞여 있습니다: ① 집단이 달라서(신호), ② 같은 집단 안에서도 개체가 달라서(잡음). ANOVA는 전체 변동을 이 둘로 분해합니다.

$$ \underbrace{SST}_{\text{총변동}} = \underbrace{SSB}_{\text{집단 간 (신호)}} + \underbrace{SSW}_{\text{집단 내 (잡음)}} $$

각 변동을 자유도로 나눠 "평균제곱(분산 추정량)"을 만들고, 그 비를 F 통계량으로 삼습니다.

$$ F = \frac{MSB}{MSW} = \frac{SSB/(k-1)}{SSW/(N-k)} $$
왜 비(ratio)인가? 집단 간 차이(분자)가 집단 내 우연한 흔들림(분모)에 비해 몇 배나 큰지를 보는 것입니다. 신호가 잡음보다 압도적으로 크면 F가 커지고, 그러면 "집단 차이는 우연이 아니다"라고 판단합니다.

소스 코드

① scipy 방식 — 빠른 F 검정

Python · scipyoneway_scipy.py
import pandas as pd
from scipy import stats

df = pd.DataFrame({
    'A': [10.5, 11.3, 10.8, 9.6, 11.1, 10.2, 10.9, 11.4, 10.5, 10.3],
    'B': [11.9, 12.4, 12.1, 13.2, 12.5, 11.8, 12.2, 12.9, 12.4, 12.3],
    'C': [11.2, 11.7, 11.6, 10.9, 11.3, 11.1, 10.8, 11.5, 11.4, 11.0],
    'D': [9.8, 9.4, 9.1, 9.5, 9.6, 9.9, 9.2, 9.7, 9.3, 9.4],
})

# 일원분산분석: 집단별 배열을 그대로 전달
f_stat, p_val = stats.f_oneway(df['A'], df['B'], df['C'], df['D'])
print(f"F = {f_stat:.4f}, p-value = {p_val:.3e}")
print("결론:", "H0 기각 (평균 차이 있음)" if p_val < 0.05 else "H0 채택")
출력F = 89.1261, p-value = 1.002e-16 결론: H0 기각 (평균 차이 있음)

② statsmodels OLS 방식 — ANOVA 표 출력

Python · statsmodelsoneway_ols.py
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols

# wide → long (tidy) 형태로 변환
long = df.melt(var_name='group', value_name='value')

# ANOVA = '범주형 변수 하나를 가진 선형회귀'
model = ols('value ~ C(group)', data=long).fit()
anova_table = sm.stats.anova_lm(model, typ=2)
print(anova_table)

PART II 카이제곱의 원리

원리 — 관측 빈도와 기대 빈도의 거리

카이제곱은 "효과/연관이 없다면 각 칸에 몇 개가 들어가야 하는가(기대도수 E)"를 먼저 계산하고, 실제 빈도 O가 거기서 얼마나 벗어났는지를 제곱해서 E로 정규화한 뒤 모두 더합니다.

$$ \chi^2 = \sum_i \frac{(O_i - E_i)^2}{E_i} $$
왜 E로 나누나? 같은 크기의 차이라도 기대도수가 작은 칸에서는 더 "큰 사건"입니다. E로 나눠 상대적 비중을 맞춰 줍니다. 또한 제곱하므로 양·음 편차가 상쇄되지 않고 모두 누적됩니다.

기대도수를 정의하는 방식이 곧 검정 유형을 결정합니다: 적합도는 이론 확률로, 독립성·동질성은 주변합의 곱 ÷ 총합으로 E를 만듭니다.

$$ \text{(분할표)}\quad E_{ij} = \frac{(\text{행 합}_i)\times(\text{열 합}_j)}{N} $$

예제 ① 적합도 — 주사위는 공정한가?

120번 던졌을 때 공정하다면 각 눈은 $120/6=20$회 기대됩니다.

눈123456χ²

기대 E202020202020

df = 6−1 = 5 · 임계값 $\chi^2_{0.05}(5)=11.07$ · p = 0.48

결론 $4.50 < 11.07$ → 기각 못함. 주사위가 불공정하다는 증거는 없습니다.

예제 ② 독립성 — 성별과 음료 선호

200명의 성별 × 선호 음료 분할표입니다. 독립이라면 $E_{ij}=$ 행합×열합/200.

$$ \chi^2 = 2\!\left[\frac{10^2}{30}+\frac{10^2}{40}+\frac{0^2}{30}\right] = 2(3.333+2.5+0) = 11.667 $$

df = (2−1)(3−1) = 2 · 임계값 $\chi^2_{0.05}(2)=5.99$ · p = 0.0029

결론 $11.67 > 5.99$ → 기각. 성별과 음료 선호는 유의한 연관이 있습니다.

소스 코드

① 적합도 검정

Python · scipychi_gof.py
from scipy import stats

observed = [16, 24, 18, 25, 22, 15]   # 관측도수
expected = [20, 20, 20, 20, 20, 20]   # 공정한 주사위의 기대도수

chi2, p = stats.chisquare(f_obs=observed, f_exp=expected)
print(f"chi2 = {chi2:.4f}, df = {len(observed)-1}, p = {p:.4f}")
print("결론:", "공정하지 않음" if p < 0.05 else "공정하다고 볼 수 있음")
출력chi2 = 4.5000, df = 5, p = 0.4799 결론: 공정하다고 볼 수 있음

② 독립성 검정 (분할표)

Python · scipychi_independence.py
import numpy as np
from scipy import stats

# 행=성별(남,여), 열=음료(커피,차,주스)
table = np.array([[40, 30, 30],
                  [20, 50, 30]])

chi2, p, dof, expected = stats.chi2_contingency(table, correction=False)
print("기대도수 E:\n", expected)
print(f"chi2 = {chi2:.4f}, df = {dof}, p = {p:.4f}")
print("결론:", "연관 있음 (독립 아님)" if p < 0.05 else "독립")
출력기대도수 E: [[30. 40. 30.] [30. 40. 30.]] chi2 = 11.6667, df = 2, p = 0.0029 결론: 연관 있음 (독립 아님)
실무 팁 원자료가 분할표가 아니라 개별 행(레코드) 형태라면 pd.crosstab(df['성별'], df['음료']) 로 표를 먼저 만든 뒤 chi2_contingency 에 넣습니다. 모든 칸의 기대도수가 5 이상인지 확인하세요.

공통 판정 흐름

귀무가설(=효과 없음) → 기대값 계산 → 관측과의 차이를 검정통계량으로 → 기준분포(F · χ²) → 우측 기각역 비교 → p < 0.05면 기각
한 줄 정리 분산분석은 연속형 자료의 "평균 차이"를 분산의 비로, 카이제곱은 범주형 자료의 "분포 차이"를 도수의 제곱합으로 측정합니다. 표현 도구만 다를 뿐, "관측이 우연의 기대를 넘어서는가"를 묻는 본질은 동일합니다.
