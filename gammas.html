📋 데이터셋 소개

gammas는 인지신경과학 실험에서 측정한 감마(γ) 주파수 대역 뇌 진동 신호 데이터입니다. 안구운동(saccade)·주시 고정(fixation) 조건과 자극 방향(동측/반대측)에 따른 BOLD fMRI 신호를 기록하며, 시각 주의력과 안구운동 처리에 관여하는 뇌 영역의 기능을 연구합니다.

조건 명칭 해설

sacc_ipsi — 안구운동 동측

안구운동(saccade) 수행 시 같은 방향(동측) 반구의 BOLD 반응

sacc_contra — 안구운동 반대측

안구운동 수행 시 반대 방향(대측) 반구의 BOLD 반응 (일반적으로 더 강함)

fix_ipsi — 고정 동측

시선 고정(fixation) 시 동측 반구 기저 반응

fix_contra — 고정 반대측

시선 고정 시 반대측 반구 기저 반응

🔬 분석 방법 및 데이터 소스

출처: Fries et al., 2001 (Science) 스타일의 시각피질 감마 진동 연구. seaborn 내장 sns.load_dataset('gammas')로 로드 가능.

① 일원 분산분석 (One-way ANOVA)

4개 조건 간 BOLD 평균 차이를 검정. H₀: 모든 조건 평균 동일

② 시계열 시각화

시간에 따른 BOLD 신호 변화 프로파일 — 조건별 피크 시점 비교

③ 사후 검정 (Post-hoc)

Tukey HSD 또는 Bonferroni로 어느 조건 간 차이가 유의한지 확인

④ 히트맵 분석

조건 × 시간 구간의 평균 신호를 색상으로 표현하여 패턴 파악

📈 탐색적 데이터 분석 및 시각화

BOLD 신호 추이 & 분포

조건별 평균 & 비교

조건×시간 히트맵

💡 결과 해석

📊 통계적 유의성: One-way ANOVA F=2322.78, p=0.00e+00 → 4개 조건 간 BOLD 신호 평균이 통계적으로 유의하게 다름.
🧠 안구운동 vs 고정: sacc(안구운동) 조건이 fix(고정) 조건보다 전반적으로 높은 BOLD 신호. 안구운동 수행 시 시각피질의 더 강한 활성화를 반영.
↔️ 동측 vs 반대측: contra(반대측) 조건이 ipsi(동측)보다 강함 — 시각피질의 대측 편재화(contralateral organization) 원리.
⏱️ 시간적 패턴: 자극 후 0.5~1.0초 구간에서 피크 반응 — 시각 처리의 전형적인 혈역학 반응 함수(HRF) 형태.
⚠️ 분석 주의사항: 반복측정 설계(within-subject) → 피험자 간 변동을 제거한 반복측정 ANOVA가 더 적합. 일원 ANOVA는 보수적 추정.

💻 실행 코드

import seaborn as sns
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats
import pingouin as pg  # 반복측정 ANOVA 권장

# ① 데이터 로드
gammas = sns.load_dataset('gammas')
print(gammas.head())
print(gammas['condition'].unique())
# → ['sacc_ipsi', 'sacc_contra', 'fix_ipsi', 'fix_contra']

# ② 기술 통계
print(gammas.groupby('condition')['BOLD'].describe().round(3))

# ③ One-way ANOVA
groups = [gammas[gammas['condition']==c]['BOLD'].values
          for c in gammas['condition'].unique()]
f_stat, p_val = stats.f_oneway(*groups)
print(f"F = {f_stat:.3f},  p = {p_val:.4e}")

# ④ 반복측정 ANOVA (pingouin)
# aov = pg.rm_anova(data=gammas, dv='BOLD',
#                   within='condition', subject='subject')
# print(aov)

# ⑤ 시계열 시각화
fig, ax = plt.subplots(figsize=(10, 5))
condition_colors = {'sacc_ipsi':'blue','sacc_contra':'green',
                     'fix_ipsi':'orange','fix_contra':'red'}
for cond, color in condition_colors.items():
    sub = gammas[gammas['condition']==cond].groupby('timepoint')['BOLD'].mean()
    ax.plot(sub.index, sub.values, color=color, linewidth=2, label=cond)
ax.axhline(0, color='gray', linewidth=0.8, linestyle='--')
ax.legend(); ax.set_xlabel('Time (s)'); ax.set_ylabel('BOLD Signal')
ax.set_title('Gamma BOLD Signal by Condition')
plt.tight_layout(); plt.show()

# ⑥ 박스플롯 (seaborn 스타일)
sns.boxplot(data=gammas, x='condition', y='BOLD',
            palette=['blue','green','orange','red'])
plt.title('BOLD Distribution by Condition')
plt.tight_layout(); plt.show()
