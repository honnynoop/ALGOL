📌 데이터셋 개요

1912년 타이타닉 호 침몰 사고의 탑승객 데이터. survived(생존여부 0/1)를 타깃으로 하는 이진 분류의 교과서적 예제. 결측값, 범주형 변수, 수치형 변수가 혼재하여 전처리 실습에 최적.

🎯 주요 활용

결측값 탐색 및 처리 (age, embarked, deck 등 결측 다수), 범주형 인코딩 (sex, embarked), 생존율 그룹 분석, 로지스틱 회귀 / 랜덤포레스트 분류기 입력.

🔑 핵심 원리 — 결측값 처리

age처럼 연속형은 중앙값·평균으로 대체 (fillna(median)). embarked처럼 범주형은 최빈값으로 대체. deck처럼 결측 비율이 77%를 넘으면 열 삭제를 고려. isnull().sum()으로 먼저 결측 현황을 파악하는 게 필수 절차.

🔑 핵심 원리 — groupby 생존율

groupby('pclass')['survived'].mean()처럼 그룹별 평균으로 생존율 계산. pivot_table로 sex × pclass 2차원 생존율 매트릭스 생성. 시험에서 "성별·등급별 생존율을 구하시오" 유형 빈출.

python
import seaborn as sns
import pandas as pd
import numpy as np

# ① 데이터 로드
df = sns.load_dataset('titanic')
print(df.shape)          # (891, 15)
print(df.dtypes)
print(df.head())

# ② 결측값 파악
missing = df.isnull().sum().sort_values(ascending=False)
missing_pct = (df.isnull().mean() * 100).round(1)
print(pd.DataFrame({'count': missing, 'pct': missing_pct}))

# ③ 결측값 처리
df['age'] = df['age'].fillna(df['age'].median())
df['embarked'] = df['embarked'].fillna(df['embarked'].mode()[0])
df = df.drop(columns=['deck'])  # 결측 77% → 삭제

# ④ 그룹별 생존율
surv_sex = df.groupby('sex')['survived'].mean().round(3)
surv_cls = df.groupby('pclass')['survived'].mean().round(3)
print("성별 생존율:\n", surv_sex)
print("등급별 생존율:\n", surv_cls)

# ⑤ 2차원 피벗 — sex × pclass
pivot = df.pivot_table(
    values='survived', index='sex',
    columns='pclass', aggfunc='mean'
).round(3)
print(pivot)

# ⑥ 피처 엔지니어링 — 가족 규모
df['family_size'] = df['sibsp'] + df['parch'] + 1
df['is_alone'] = (df['family_size'] == 1).astype('int')

# ⑦ 원-핫 인코딩
df_enc = pd.get_dummies(df[['pclass','sex','age',
                              'fare','embarked','survived']],
                         drop_first=True)
print(df_enc.head())
📈 결과 해석 포인트
  • 성별 생존율: female ≈ 0.742, male ≈ 0.189 → 여성 생존율이 약 4배 높음. "여성과 어린이 먼저" 원칙 반영.
  • 등급별 생존율: 1등급 ≈ 0.630, 2등급 ≈ 0.473, 3등급 ≈ 0.242 → 높은 등급일수록 생존 가능성 큼.
  • pivot_table 해석: 1등급 여성(0.968)이 가장 높고, 3등급 남성(0.135)이 가장 낮음. 성별 효과가 등급 효과보다 더 강함.
  • 결측값 처리 후: age 중앙값(28.0)으로 대체 시 분포가 일부 왜곡될 수 있으므로, 시험에서는 "중앙값으로 대체했다"는 명시가 중요.
⚠ 빅분기 시험 포인트: isnull().sum()으로 결측 개수 확인, fillna(df['age'].median()) 정확한 문법 암기. pivot_table에서 aggfunc='mean'으로 생존율 계산하는 패턴 숙지.

150행 × 5열 다중분류 PCA·클러스터링 빅분기 ADP
📌 데이터셋 개요

3종 붓꽃(setosa, versicolor, virginica)의 꽃받침·꽃잎 크기를 측정한 고전 데이터셋. 결측값이 없어 전처리 부담이 낮고, 다중 분류·PCA·클러스터링의 기준 데이터로 가장 많이 사용됨.

🎯 주요 활용

describe()로 기초통계 확인, groupby로 종별 평균 비교, PCA 2차원 축소 후 산점도, K-Means 군집과 실제 레이블 비교, 상관 히트맵.

🔑 핵심 원리 — 상관분석 + PCA

petal_length와 petal_width의 상관계수가 0.96에 달해 강한 양의 상관. PCA 전에 반드시 표준화(StandardScaler)를 적용해야 스케일 차이로 인한 왜곡을 방지. PC1이 전체 분산의 약 73%를 설명하며 꽃잎 크기 정보를 대표.

python
import seaborn as sns
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans

df = sns.load_dataset('iris')

# ① 기초 통계
print(df.describe())

# ② 종별 그룹 평균
print(df.groupby('species').mean().round(2))

# ③ 상관행렬
corr = df.select_dtypes('number').corr()
print(corr.round(2))

# ④ 표준화 + PCA
X = df.select_dtypes('number')
scaler = StandardScaler()
X_sc = scaler.fit_transform(X)

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_sc)
df_pca = pd.DataFrame(X_pca, columns=['PC1','PC2'])
df_pca['species'] = df['species'].values
print("설명 분산비:", pca.explained_variance_ratio_.round(3))

# ⑤ K-Means 클러스터링
km = KMeans(n_clusters=3, random_state=42)
df['cluster'] = km.fit_predict(X_sc)
print(pd.crosstab(df['species'], df['cluster']))
📈 결과 해석
  • 그룹 평균: setosa는 petal_length 평균 1.46cm로 다른 종(4.26, 5.55)에 비해 현저히 작아 선형 분리 가능.
  • PCA 설명력: PC1(72.8%) + PC2(23.0%) → 2개 주성분이 전체 분산의 95.8% 설명. 4차원→2차원 축소 가능.
  • K-Means vs 실제: setosa는 완벽하게 분리, versicolor/virginica는 일부 혼재(경계 불명확).
  • 상관계수: petal_length ↔ petal_width = 0.96 (강한 양의 상관), sepal_width ↔ 나머지는 약한 음의 상관.

🔑 핵심 원리 — dropna vs fillna

결측 11행(3.2%)은 전체 대비 비율이 낮으므로 dropna()가 안전. 단, 시험에서는 "결측을 제거했는가, 대체했는가" 명확히 서술. sex가 결측인 행은 분석 목적에 따라 제거(성별 분석) vs 유지(전체 분석) 선택.

python
df = sns.load_dataset('penguins')

# ① 결측 현황
print(df.isnull().sum())

# ② 결측 제거 (2개 수치 결측행 + sex 결측 11개)
df_clean = df.dropna()   # 333행 남음

# ③ 종 × 성별 그룹 집계
summary = df_clean.groupby(['species','sex'])[[
    'bill_length_mm','body_mass_g'
]].agg(['mean','std']).round(1)
print(summary)

# ④ 교차빈도표 — 종 × 섬
ct = pd.crosstab(df_clean['species'], df_clean['island'])
print(ct)

# ⑤ 카이제곱 검정
from scipy.stats import chi2_contingency
chi2, p, dof, expected = chi2_contingency(ct)
print(f"χ²={chi2:.2f}, p={p:.4f}, df={dof}")
📈 결과 해석
  • Gentoo 수컷이 평균 체중 5485g으로 가장 무거움. 암수 차이도 Gentoo에서 가장 큼(~700g).
  • 교차빈도표: Chinstrap은 Dream 섬에만 서식. Gentoo는 Biscoe 섬에만. Adelie는 3개 섬 모두.
  • 카이제곱: p < 0.001 → 종과 서식지 사이에 유의한 관계. 귀무가설(독립) 기각.

레스토랑 팁 데이터. total_bill(식사비)과 tip(팁) 관계 분석, 성별·흡연·요일·시간대별 팁 차이 분석에 활용. 범주형 변수가 풍부해 groupby·pivot·get_dummies 종합 실습에 최적.

🔑 핵심 원리

tip_rate = tip / total_bill × 100으로 파생변수를 만들면 절대 팁액 대신 비율로 비교 가능. category 타입은 .cat.codes나 pd.get_dummies()로 수치화. 다중 groupby는 .agg({'tip':'mean','total_bill':'sum'})처럼 컬럼별 다른 집계 함수 지정.

python
df = sns.load_dataset('tips')

# ① 팁 비율 파생변수
df['tip_rate'] = (df['tip'] / df['total_bill'] * 100).round(2)

# ② 성별 × 흡연 × 요일 집계
g = df.groupby(['sex','smoker']).agg(
    tip_mean=('tip','mean'),
    tip_rate_mean=('tip_rate','mean'),
    count=('tip','count')
).round(2)
print(g)

# ③ 상관계수
print(df[['total_bill','tip','size','tip_rate']].corr().round(3))

# ④ 요일별 총매출 피벗
piv = df.pivot_table(
    values=['total_bill','tip'],
    index='day', columns='time',
    aggfunc='sum'
).round(1)
print(piv)

# ⑤ 선형회귀
from sklearn.linear_model import LinearRegression
X = df[['total_bill','size']]
y = df['tip']
lr = LinearRegression().fit(X, y)
print(f"R²={lr.score(X,y):.3f}, 절편={lr.intercept_:.3f}")
print(f"계수={dict(zip(['total_bill','size'], lr.coef_.round(3)))}")

NASA 외계행성 탐지 데이터. mass(질량), distance(거리), orbital_period(공전주기) 등에 결측값 대량 포함. 극단적으로 오른쪽 치우친 분포로 로그 변환이 필수. 탐지 방법별(method) 그룹 분석.

컬럼설명결측
method발견 방법없음
number행성 수없음
orbital_period공전 주기 (일)⚠ 111개
mass행성 질량 (목성 대비)⚠ 522개
distance거리 (파섹)⚠ 227개
year발견 연도없음
python
df = sns.load_dataset('planets')
import numpy as np

# ① 결측 현황
print((df.isnull().sum() / len(df) * 100).round(1))

# ② 방법별 발견 수 & 연도 범위
print(df.groupby('method').agg(
    count=('number','count'),
    first_year=('year','min'),
    last_year=('year','max')
))

# ③ 로그 변환 (오른쪽 치우침 완화)
df['log_mass'] = np.log10(df['mass'])
df['log_dist'] = np.log10(df['distance'])
df['log_period'] = np.log10(df['orbital_period'])

# ④ 연도별 탐지 수 추이
print(df.groupby('year')['number'].sum())
📈 결과 해석
  • 결측 비율: mass 50.4%, distance 21.9% → mass는 모델 입력에서 제외하거나 따로 분석.
  • 발견 방법: Radial Velocity(268개)가 가장 오래되고 많음. Transit(Transit photometry)이 케플러 위성 이후 폭발적 증가.
  • 로그 변환: orbital_period 범위가 0.09일~730,000일 → log 변환 필수.

🧩 attention
60행 × 5열 반복측정ANOVA ADP
📌 개요

주의력 실험 데이터. 피험자, 솔루션 유형(focused/divided), 점수(score), 조건(attention type). 2×3 반복측정 실험 설계. groupby로 조건별 평균 비교 후 일원/이원 ANOVA 검정에 활용.

python
df = sns.load_dataset('attention')
print(df.head())
print(df.columns.tolist())

# ① 조건별 평균 점수
print(df.groupby(['solutions','attention'])['score'].agg(['mean','std']).round(2))

# ② 일원 ANOVA (solutions 그룹 간)
from scipy.stats import f_oneway
g1 = df[df['solutions']==1]['score']
g2 = df[df['solutions']==2]['score']
g3 = df[df['solutions']==3]['score']
F, p = f_oneway(g1, g2, g3)
print(f"F={F:.3f}, p={p:.4f}")

# ③ 교호작용 확인 — 이원 집계
pivot = df.pivot_table(
    values='score', index='attention',
    columns='solutions', aggfunc='mean'
).round(2)
print(pivot)
📈 결과 해석
  • ANOVA F 값: p < 0.05이면 최소 한 그룹 간 평균 차이 유의. 사후 검정(Tukey HSD)으로 어떤 쌍이 다른지 확인.
  • 교호작용: pivot_table에서 행과 열 조합에 따라 점수 차이 패턴이 달라지면 교호작용 존재.
🏃 exercise
90행 × 6열 그룹비교 ADP
📌 개요

운동 종류(rest/walk/run)와 식이요법(no fat/low fat) 조합별 심박수 변화를 측정. 반복측정(시점: 1분, 15분, 30분) 포함. 이원 ANOVA, 그룹별 시계열 비교에 활용.

컬럼설명
id피험자 ID
diet식이요법 (no fat / low fat)
pulse심박수 (bpm)
time측정 시점 (1 / 15 / 30분)
kind운동 종류 (rest / walk / run)
python
df = sns.load_dataset('exercise')

# ① 운동 종류 × 시점별 평균 심박수
print(df.groupby(['kind','time'])['pulse'].mean().round(1))

# ② 식이요법 × 운동 이원 분석
pivot = df.pivot_table(
    values='pulse', index='kind',
    columns='diet', aggfunc='mean'
).round(1)
print(pivot)

# ③ 운동 간 t-검정 (run vs rest)
from scipy.stats import ttest_ind
run  = df[df['kind']=='run']['pulse']
rest = df[df['kind']=='rest']['pulse']
t, p = ttest_ind(run, rest)
print(f"t={t:.3f}, p={p:.6f}")
📈 결과 해석
  • 운동 효과: run > walk > rest 순으로 심박수 높음. 30분에서 격차 최대.
  • 식이요법 효과: 식이요법(no fat vs low fat) 간 차이는 작음. 운동 종류 효과가 지배적.
  • t-검정: run vs rest p < 0.001 → 강하게 유의. 두 그룹 심박수 차이는 통계적으로 확실.

📐 anscombe
44행 × 3열 시각화 필요성 ADP
📌 개요

앤스컴의 4분류. 4개 그룹(I/II/III/IV)이 평균·분산·상관계수·회귀계수 모두 거의 동일하지만 산점도는 완전히 다른 분포. "숫자만 믿지 말고 시각화하라"는 가장 유명한 데이터 예제.

python
df = sns.load_dataset('anscombe')

# ① 4그룹의 통계 비교 — "동일한" 통계
stats = df.groupby('dataset')[['x','y']].agg(['mean','var']).round(2)
print(stats)

# ② 그룹별 상관계수 & 회귀계수
from scipy.stats import linregress
for name, grp in df.groupby('dataset'):
    slope, intercept, r, p, se = linregress(grp['x'], grp['y'])
    print(f"{name}: slope={slope:.2f}, intercept={intercept:.2f}, r²={r**2:.2f}")

# ③ 결과: 통계는 같지만 시각화하면 완전히 다른 분포 확인
# → 반드시 항상 시각화로 분포 확인 필요!
📈 결과 해석 — 핵심 메시지
  • 4그룹 공통 통계: x̄ ≈ 9.0, ȳ ≈ 7.5, x분산 ≈ 11, y분산 ≈ 4.12, r ≈ 0.816, slope ≈ 0.5.
  • I: 선형 관계 (정상). II: 곡선(2차) 관계. III: 선형이지만 이상치 1개. IV: 수직 분포에 이상치 1개.
  • 교훈: 기술통계만으로는 데이터 구조를 파악할 수 없다. 시각화 → 기술통계 순서가 올바른 EDA.
⚠ ADP 단골 서술형: "왜 기술통계만으로는 충분하지 않은가?" → 앤스컴의 4분류를 예시로 시각화의 필요성 서술.

🔑 핵심 원리 — datetime 처리

df['pickup'] = pd.to_datetime(df['pickup']) 후 .dt.hour, .dt.dayofweek, .dt.month로 시간 특성 추출. 두 datetime 컬럼 차이로 이동시간(timedelta) 계산 후 .dt.total_seconds() / 60로 분 단위 변환.

python
df = sns.load_dataset('taxis')

# ① datetime 변환
df['pickup']  = pd.to_datetime(df['pickup'])
df['dropoff'] = pd.to_datetime(df['dropoff'])

# ② 시간 특성 추출
df['hour']      = df['pickup'].dt.hour
df['dayofweek']  = df['pickup'].dt.dayofweek  # 0=월
df['is_weekend'] = df['dayofweek'].isin([5,6])

# ③ 이동 시간 (분)
df['duration_min'] = (df['dropoff'] - df['pickup']).\
                    dt.total_seconds() / 60

# ④ 시간대별 평균 요금
print(df.groupby('hour')[['fare','tip','total']].mean().round(2))

# ⑤ 결제수단별 팁 비율
df['tip_rate'] = df['tip'] / df['fare']
print(df.groupby('payment')['tip_rate'].mean().round(3))

# ⑥ 상위 승차 구역 TOP5
print(df['pickup_zone'].value_counts().head(5))

# ⑦ 행정구별 평균 이동거리
print(df.groupby('pickup_borough')['distance'].agg(['mean','median']).round(2))
📈 결과 해석
  • 시간대: 야간(22시~3시) 및 출퇴근 시간대(8시, 18시)에 요금 높음. 거리 대비 야간 할증 반영.
  • 결제수단: credit card 이용 시 팁 비율 약 22%. cash는 거의 0% (현금 팁은 데이터에 미기록).
  • 주요 승차지: JFK Airport, Midtown Center 등 관광·교통 허브 상위권.
  • 행정구: Staten Island 평균 이동거리 가장 길고, Manhattan이 이동 건수 가장 많음.
  • dt 접근자: .dt.dayofweek는 0(월)~6(일). isin([5,6])으로 주말 필터링 패턴 빅분기 단골.

🔑 핵심 원리 — clustermap

상관행렬이 이미 주어진 경우 sns.clustermap(corr_matrix)로 행/열을 계층 클러스터링 순서로 재정렬. 유사한 ROI끼리 블록을 이루어 뇌 기능 네트워크(시각/청각/운동 피질 등)를 시각화. method='ward', metric='euclidean'이 기본.

python
# ⚠ brain_networks는 멀티인덱스 컬럼 — header=[0,1] 필요
df = sns.load_dataset('brain_networks',
                       header=[0,1], index_col=0)

# ① 컬럼 레벨 확인
print(type(df.columns))          # MultiIndex
print(df.columns.levels)         # 레벨 확인
print(df.shape)                   # (87, 87) 예상

# ② 숫자형만 추출 후 상관행렬
df_num = df.select_dtypes('number')
corr = df_num.corr()

# ③ 상위 N개 고상관 ROI 쌍 찾기
import numpy as np
mask = np.triu(np.ones(corr.shape), k=1).astype('bool')
corr_pairs = corr.where(mask).stack().\
             sort_values(ascending=False)
print("Top 10 고상관 ROI 쌍:\n", corr_pairs.head(10).round(3))

# ④ 네트워크별 평균 연결성
network_corr = corr.mean().sort_values(ascending=False)
print("네트워크별 평균 연결성 (상위 10):\n", network_corr.head(10).round(3))

# ⑤ 클러스터 분석 (계층 클러스터링)
from scipy.cluster.hierarchy import linkage, fcluster
link = linkage(corr, method='ward')
clusters = fcluster(link, t=5, criterion='maxclust')
print("5개 클러스터 크기:", pd.Series(clusters).value_counts())
📈 결과 해석
  • 멀티인덱스: 컬럼이 (네트워크명, ROI번호) 2레벨. df.columns.get_level_values(0)로 네트워크명 추출.
  • 상관 구조: 같은 기능 네트워크(예: 시각 피질) ROI끼리 r > 0.8의 강한 상관. 다른 네트워크 간은 낮거나 음수.
  • stack() 패턴: 상관행렬에서 상삼각(triu)만 추출 후 stack()으로 쌍-상관값 시리즈 변환 → 상위 상관쌍 순위화. ADP 분석 리포트에 자주 사용.
  • 계층 클러스터링: 5개 클러스터로 분류 시 뇌의 주요 기능 네트워크(Default Mode Network, Visual, Somatomotor 등)와 유사하게 묶임.
⚠ 주의: brain_networks는 로드 방식이 다른 데이터셋과 다름. 시험/실습에서 header=[0,1], index_col=0 반드시 지정.
